Enter your parameters

Start with a blank worksheet. Put Success probability, Trials per experiment, Experiments, and Failure probability in A2:A5. Enter the generated p and n in B2 and B3. Enter the probability as a percentage such as 40%. Put 100 in B4 and =1-B2 in B5.

Build the theoretical probability triangle

After one more trial, exactly k successes can come from k successes followed by a failure, or from k − 1 successes followed by a success. Multiply the cell directly above by the failure probability, multiply the cell above-left by the success probability, and add the results.

  1. Put Trials so far in A8. In C8 and to its right, enter the success counts 0 through n. In A9 and below, enter the trial counts 0 through n. Keep column B blank beside the triangle so the first column has a blank above-left cell.
  2. Enter 1 in C9. With zero trials there are zero successes with probability 1. Leave the rest of row 9 in the triangle blank.
  3. Enter =IF(C$8>$A10,"",$B$5*N(C9)+$B$2*N(B9)) in C10. Fill it right through the column for n successes, then fill that row down through the row for n trials. The IF displays an empty cell when successes exceed trials. N treats a blank or empty text as zero and leaves a probability unchanged.
  4. Read the theoretical distribution from the last row. Its first and last probabilities should be (1 − p)n and pn.

As a small practice example, with p = 40% the row for one trial is 60%, 40%. The row for two trials is 36%, 48%, 16%. After three trials the row is 21.6%, 43.2%, 28.8%, 6.4%.

Simulate 100 experiments

  1. Starting in P7, label the trials 1 through n. In P8 enter =IF(RAND()<$B$2,1,0). Fill it across the n trial columns and down through row 107. Each row is one experiment. Leave unused trial columns through AA empty.
  2. Put Successes in AB7. Enter =SUM(P8:AA8) in AB8 and fill down through AB107. The sum counts the 1s in that experiment. Use =COUNT(AB8:AB107) in a spare cell to confirm you have 100 numerical totals.

RAND() generates a new value when Excel recalculates. The simulated counts can change while the theoretical probabilities stay fixed for the same inputs. Microsoft’s RAND reference

Summarize the two distributions

In A24:D24, enter Successes, Theoretical probability, Simulated count, and Simulated relative frequency. Start with 0 in A25 and list each possible success count up to n. Enter these formulas and fill down through the last listed count.

CellFormula
B25=INDEX($C$9:$O$21,$B$3+1,A25+1)
C25=COUNTIF($AB$8:$AB$107,A25)
D25=C25/$B$4

INDEX reads the triangle row for n trials and the column for the listed success count. The two offsets account for the row and column that start at zero. Format B and D as percentages. Use SUM below the data to check that the columns total 100%, 100, and 100%, respectively.

Make two line charts on the same worksheet

  1. For the theoretical chart, plot the data in column B using Line with Markers. In Select Data, set the horizontal category labels to the success counts in column A. Include every category from 0 through n and leave out the totals.
  2. Repeat with the relative frequencies in column D. Use the same column A labels. Give the charts distinct titles and place them side by side.
  3. Format both vertical axes as percentages with the same bounds. Start both at 0% and choose an upper bound high enough for both charts. Compare where they peak and how the probabilities change as the success count moves away from the peak. A simulation of 100 experiments can have a different peak or a more jagged shape.

      Learn the workflow and see a worked example

      What to learn

      Turn a line of comma-separated numbers into individual numeric cells, arrange the observations in one column, and summarize them with formulas. Keep the original text available so you can check your work.

      Practice example

      Paste this entire line into cell A1 as text:

      12,8,15,10,7,14,9,11,13,6,16,10,8,12,9
      1. Copy A1 to A3. Select A3 and use Data → Text to Columns → Delimited → Comma. The 15 observations should occupy A3:O3; leave the cells to the right empty before splitting. If the menus look different, choose the available split-by-delimiter tool and select comma.
      2. Copy A3:O3. Select A6 and use Paste Special → Transpose so the observations occupy A6:A20. Paste values if necessary: the final column must contain individually editable numbers.
      3. Select only A6:A20 and sort smallest to largest. Be able to sort largest to smallest as well. With a multi-column record list, select the whole record range before sorting so related fields stay together.
      4. In a separate labeled summary area, calculate the number of observations with =COUNT(A6:A20) and the mean with =AVERAGE(A6:A20). Confirm the count is 15 and the mean is approximately 10.6667. A count below 15 may mean some entries are still text.
      5. Change the largest observation from 16 to 26. Confirm the mean becomes approximately 11.3333 and the count stays 15. The original text should still be available in A1.

      (Excel for the web or a version without the wizard: enter =TEXTSPLIT(A1,",") in A3 if available, then copy its results and paste transposed values into A6. Google Sheets: select the copied text and use Data → Split text to columns, choosing comma; then use Edit → Paste special → Transposed. You can also split with =SPLIT(A1,","). Convert formula results to values before sorting or editing individual observations.)

      During your check

      From a new supplied line of data, create a sorted, editable column and a formula-based count and mean. Make one requested correction and show the summary updating.

      Variations to prepare for

      • A different number of observations or a different destination cell.
      • Semicolons or tabs as the delimiter; negative or decimal values.
      • Descending instead of ascending order, or deleting a specified observation. If deleting, ensure the summary still includes all remaining observations.

      Be ready to explain

      Why one cell containing a whole line of text is not yet a column of numerical observations, and how you verified that no observations were lost.

Compare Binomial Theory and Simulation

Each experiment consists of n independent trials. Each trial has the same probability p of success. The outcome of an experiment is the total number of successes in its n trials.

Requirements

  1. Use one Excel worksheet for the inputs, probability triangle, simulation, summary, and both charts.
  2. Build a probability triangle from 0 through n trials. Use each previous row to calculate the next, weighting the two contributing cells by p and 1 − p. The final row gives the theoretical probabilities for 0 through n successes and must sum to 100%.
  3. Use IF and RAND to simulate n independent trials across each of 100 rows. Record a 1 for success and a 0 for failure. Use SUM to count successes in each row.
  4. Use COUNTIF to count how many of the 100 experiments gave each possible number of successes. Include outcomes with zero occurrences. Divide the counts by 100 to get relative frequencies.
  5. Make two separate line charts with markers on the same worksheet, one for the theoretical probabilities and one for the simulated relative frequencies. Use the same success-count labels and vertical percentage scale on both charts.
  6. Show where the two distributions tend to peak and point out one difference you see. The comparison should use the simulation you obtained, with its natural variation from 100 experiments.

4.1: Probability Distribution Function (PDF) for a Discrete Random Variable

A discrete probability distribution function has two characteristics:

  1. Each probability is between zero and one, inclusive.
  2. The sum of the probabilities is one.

Example 4.1

Let X count the weekly after-midnight awakenings in the textbook study. For 50 observations, the frequencies of x = 0,1,2,3,4,5 are 2,11,23,9,4,1. Construct a probability distribution and verify its two required properties.

Every probability is between 0 and 1, and their sum is 50/50 = 1. X has a finite, countable set of possible values.

P(x) = the probability that X takes on value x. Why is this a discrete probability distribution function (two reasons)?

The possible values 0–5 form a discrete set. Each probability is in [0,1], and (4 + 8 + 16 + 14 + 6 + 2)/50 = 1. These verify a discrete probability distribution.

Try It 4.2

Jeremiah has basketball practice two days a week. Ninety percent of the time, he attends both practices. Eight percent of the time, he attends one practice. Two percent of the time, he does not attend either practice. What is X and what values does it take on?

X = number of practices attended in a week. Its possible values are 0, 1, 2, with probabilities 0.02, 0.08, 0.90, respectively.

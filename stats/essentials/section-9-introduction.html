Check short-answer key
  1. Competing claims about a population parameter, with the equality boundary in the null.
  2. Assuming the null model and its conditions, the probability of a result at least as extreme as observed in the direction(s) of the alternative.
  3. Rejecting a true null hypothesis.
  4. Failing to reject a false null hypothesis.
  5. Reject H₀ if p-value ≤ α; otherwise fail to reject H₀.

Example problems

Example 1

A claim is that mean completion time is 12 minutes. Test whether it differs, given p-value 0.03 and α = 0.05.

Show solution
  1. Set H₀: μ = 12 and Hₐ: μ ≠ 12.
  2. Because 0.03 < 0.05, reject H₀.
  3. The data provide evidence that the population mean differs from 12, assuming the test's conditions hold; the p-value is not the probability that H₀ is true.

Example 2

A test for p > 0.60 has p-value 0.18 at α = 0.05. State the conclusion and describe a possible Type II error.

Show solution
  1. Since 0.18 > 0.05, fail to reject H₀.
  2. There is insufficient evidence that the population proportion exceeds 0.60; this does not prove the null.
  3. A Type II error would occur if the true proportion exceeds 0.60 but the test fails to detect it.

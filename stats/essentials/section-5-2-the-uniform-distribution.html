Statistics

5.2: The Uniform Distribution · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is a uniform density on [a, b]?
  2. How is probability found within its support?
  3. What is its mean?
  4. What is its standard deviation?
  5. Do equal-length subintervals have equal probabilities?
Check short-answer key
  1. A constant density 1/(b − a), with b > a.
  2. Interval length divided by total support length.
  3. (a + b)/2.
  4. (b−a)/12.
  5. Yes, when both lie within the support.

Example problems

Example 1

A waiting time is uniform from 0 to 10 minutes. Find P(2 ≤ X ≤ 5).

Show solution
  1. The interval length is 3; the full support length is 10.
  2. Probability = 3/10 = 0.3.

Example 2

For X uniform on [4, 16], find mean and SD.

Show solution
  1. Mean = (4 + 16)/2 = 10.
  2. SD = (16 − 4)/√12 = √12 ≈ 3.46.
  3. A central interval [7, 13] has probability 6/12 = 0.5.

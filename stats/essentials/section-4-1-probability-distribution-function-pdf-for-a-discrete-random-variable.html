  1. A numerical value assigned to each outcome of a random experiment.

  3. Every probability is between 0 and 1, and all probabilities sum to 1.
  4. Add probabilities for the listed values in that set.
  5. Its possible values with positive probability.

Example problems

Example 1

X has values 0, 1, 2 with probabilities 0.2, 0.5, 0.3. Verify validity and find P(X ≥ 1).

Show solution
  1. All probabilities lie between 0 and 1 and sum to 1.
  2. P(X ≥ 1) = 0.5 + 0.3 = 0.8.

Example 2

A table lists probabilities 0.15, 0.25, and k for three possible outcomes. Find k.

Show solution
  1. A complete distribution must sum to 1.
  2. k = 1 − 0.15 − 0.25 = 0.60.
  3. This is a valid probability because it lies between 0 and 1.

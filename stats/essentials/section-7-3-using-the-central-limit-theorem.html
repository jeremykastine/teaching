7.3: Using the Central Limit Theorem · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What should you identify before standardizing a probability question?
  2. Which SD belongs to a sample mean?
  3. Which SD belongs to a sum of n independent observations?
  4. Why does independence matter?
  5. What happens to a mean's SE when sample size quadruples?
Check short-answer key
  1. Whether the variable is an individual observation, sample mean, or sum.
  2. σ/√n.
  3. σ√n.
  4. Dependence can change the variance and invalidate the usual standard-error formulas.
  5. It is halved, with the same population SD.

Example problems

Example 1

A normal population has mean 100 and SD 20. Compare the z-scores for an individual value 110 and a sample mean 110 with n = 16.

Show solution
  1. Individual z = (110 − 100)/20 = 0.5.
  2. Mean SE = 20/4 = 5; mean z = (110 − 100)/5 = 2.
  3. The same numerical deviation is more unusual for a sample mean.

Example 2

How large must n be for a sample mean's SE to be at most 3 if σ = 18?

Show solution
  1. Solve 18/√n ≤ 3.
  2. This requires √n ≥ 6, so n ≥ 36.
  3. This precision calculation alone does not establish normality or correct a biased design.

8.2: A Single Population Mean using the Student t Distribution · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. Why use Student's t for a mean interval?
  2. What degrees of freedom are used for a one-sample t interval?
  3. What is its standard error estimate?
  4. What is the interval formula?
  5. What conditions need special care for a small sample?
Check short-answer key
  1. The population SD is unknown and is estimated with sample SD s.
  2. n − 1.
  3. s/√n.
  4. x¯±t*s/n.
  5. Independent observations from an approximately normal population without severe outliers.

Example problems

Example 1

For x̄ = 20, s = 4, n = 16, find a 95% t interval using t* = 2.131 and assuming conditions hold.

Show solution
  1. df = 15 and estimated SE = 4/4 = 1.
  2. Margin = 2.131.
  3. Interval: (17.869, 22.131), approximately (17.87, 22.13).

Example 2

Two samples have the same x̄ = 30 and s = 6. Compare n = 9 and n = 36 using supplied 95% critical values 2.306 and 2.030.

Show solution
  1. For n = 9, margin = 2.306(6/3) = 4.612.
  2. For n = 36, margin = 2.030(6/6) = 2.030.
  3. The larger sample gives a narrower interval under the same appropriate assumptions.

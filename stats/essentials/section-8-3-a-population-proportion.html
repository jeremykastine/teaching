8.3: A Population Proportion · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is the sample proportion?
  2. What is the usual normal-approximation confidence interval for a proportion?
  3. What counts should be checked before using that interval?
  4. What design assumptions matter?
  5. What planning value gives the largest required sample size when p is unknown?
Check short-answer key
  1. Number of successes divided by sample size: p̂ = x/n.
  2. p^±z*p^(1−p^)/n.
  3. Observed successes and failures must both be sufficiently large; use at least 10 of each here.
  4. A suitable random sample and independent observations; for sampling without replacement, the sample should be a small fraction of the population.
  5. p = 0.5.

Example problems

Example 1

In a suitable random sample, 60 of 100 respondents answer yes. Find an approximate 95% interval.

Show solution
  1. p̂ = 0.60; counts are 60 successes and 40 failures, meeting the count check.
  2. SE = √(0.6 × 0.4/100) ≈ 0.04899; margin ≈ 1.96(0.04899) = 0.09602.
  3. Interval ≈ (0.504, 0.696).

Example 2

Plan a 95% proportion interval with margin at most 0.05 and no prior estimate.

Show solution
  1. Use p = 0.5 and n≥(z*/E)2p(1−p).
  2. (1.96/0.05)²(0.25) = 384.16.
  3. Round upward to n = 385; this does not address selection bias.

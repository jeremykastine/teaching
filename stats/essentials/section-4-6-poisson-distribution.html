4.6: Poisson Distribution · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does a Poisson random variable count?
  2. What parameter defines the distribution?
  3. What assumptions support a Poisson process model?
  4. What is P(X = k)?
  5. What are its mean and variance?
Check short-answer key
  1. Events in a fixed interval of time, space, area, or another exposure.
  2. λ, the expected count for that exposure.
  3. A constant average rate, independent increments, and negligible probability of multiple events in a sufficiently small exposure.
  4. e−λλk/k!, k = 0, 1, 2, … .
  5. Both equal λ; the SD is √λ.

Example problems

Example 1

Calls follow a Poisson model averaging 2 per minute. Find P(no calls in one minute).

Show solution
  1. The exposure is one minute, so λ = 2.
  2. P(X = 0) = e⁻²(2⁰)/0! = e⁻² ≈ 0.1353.

Example 2

Defects average 3 per square meter under a Poisson model. Find the mean and SD in 2 square meters.

Show solution
  1. Double the exposure, so λ = 3 × 2 = 6.
  2. Expected count = 6 defects.
  3. SD = √6 ≈ 2.45 defects.

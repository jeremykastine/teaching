  4. (Kk)(N−Kn−k)/(Nn).

Example problems

Example 1

A box has 3 red and 2 blue objects. Choose 2 uniformly without replacement. Find P(exactly one red).

Show solution
  1. Choose 1 of 3 red and 1 of 2 blue: 3 × 2 = 6 favorable samples.
  2. All two-object samples: (52)=10.
  3. Probability = 6/10 = 0.6.

Example 2

With N = 10, K = 4, and n = 3, find the support and mean.

Show solution
  1. The smallest possible success count is max(0, 3 − 6) = 0; the largest is min(3, 4) = 3.
  2. Support: 0, 1, 2, 3.
  3. Mean = nK/N = 3(4)/10 = 1.2 successes.

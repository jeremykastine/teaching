Essential facts, definitions, and procedures

  1. What is the domain of a graph?
  2. What is the range of a graph?
  3. What does an open endpoint mean?
  4. What does a filled endpoint mean?
  5. Which brackets are used at infinity in interval notation?
Check short-answer key
  1. All x-values represented on it.
  2. All y-values represented on it.
  3. That endpoint is not included.
  4. That endpoint is included.
  5. Parentheses; infinity is not an attained endpoint.

Example problems

Example 1

Find the domain and range in interval notation.

Show solution
  1. Read horizontally: x runs from −3, included, to 2, excluded.
  2. Domain: [−3, 2).
  3. Read vertically: y runs from −2, included, to 3, excluded. Range: [−2, 3).

Example 2

Find the domain and range in interval notation.

Show solution
  1. The left endpoint is open at (−2, 4); the right endpoint is filled at (1, 1).
  2. Domain: (−2, 1].
  3. The lowest height 0 is attained at the vertex; height 4 is approached but excluded. Range: [0, 4).

Check short-answer key
  1. Squaring can introduce extraneous solutions.
  2. u = c or u = −c.
  3. There is no real solution.
  4. Substitute u = x², solve for u, then solve for x.
  5. A candidate at an excluded input is invalid.

Example problems

Example 1

Solve x+6=x.

Show solution
  1. The right side must be nonnegative, so x ≥ 0.
  2. Square: x + 6 = x², giving (x − 3)(x + 2) = 0.
  3. Check candidates: x = 3 works; x = −2 fails. The solution is 3.

Example 2

Solve x4−5x2+4=0.

Show solution
  1. Let u = x²: u² − 5u + 4 = (u − 1)(u − 4) = 0.
  2. Thus x² = 1 or 4.
  3. The real solutions are −2, −1, 1, 2.

3.4: Composition of Functions · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does (f∘g)(x) mean?
  2. Does composition generally commute?
  3. How do you compose formula rules?
  4. What inputs belong to a composition's domain?
  5. How does composition differ from multiplying functions?
Check short-answer key
  1. f(g(x)): apply g first, then f.
  2. No; f(g(x)) and g(f(x)) can differ.
  3. Replace every input variable in the outer rule with the entire inner expression.
  4. Inputs allowed by the inner function whose outputs are allowed by the outer function.
  5. Composition feeds an output into another rule; multiplication multiplies two outputs at the same input.

Example problems

Example 1

Let f(x) = 2x + 1 and g(x) = x². Find both compositions at x = 3.

Show solution
  1. g(3) = 9, so f(g(3)) = f(9) = 19.
  2. f(3) = 7, so g(f(3)) = g(7) = 49.
  3. Reversing the order changes the answer.

Example 2

For f(x) = √x and g(x) = x − 4, find f(g(x)) and its domain.

Show solution
  1. Substitute g(x) into f: x−4.
  2. The inner rule accepts every real number, but the outer root requires x − 4 ≥ 0.
  3. The domain is [4, ∞).

6.5: Logarithmic Properties · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. State the product rule for logarithms of positive arguments.
  2. State the quotient rule.
  3. State the power rule for positive M.
  4. What is the change-of-base formula?
  5. Is log(M + N) equal to log M + log N?
Check short-answer key
  1. logb(MN)=logbM+logbN.
  2. logb(M/N)=logbM−logbN.
  3. logb(Mr)=rlogbM.
  4. logbx=lnx/lnb.
  5. No; there is no corresponding sum rule.

Example problems

Example 1

Expand ln(3x2/y) for x > 0 and y > 0.

Show solution
  1. Use product and quotient rules: ln 3 + ln(x²) − ln y.
  2. Apply the power rule: ln 3 + 2 ln x − ln y.

Example 2

Condense 2log3x−log35, x > 0.

Show solution
  1. Bring 2 into the exponent: log₃(x²) − log₃5.
  2. Use the quotient rule to get log3(x2/5).
  3. Retain the original restriction x > 0.

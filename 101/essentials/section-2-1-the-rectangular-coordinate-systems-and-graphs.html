2.1: The Rectangular Coordinate Systems and Graphs · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does an ordered pair (x, y) specify?
  2. What does it mean for a point to lie on an equation's graph?
  3. How do you find intercepts?
  4. State the distance formula.
  5. State the midpoint formula.
Check short-answer key
  1. Horizontal coordinate first and vertical coordinate second.
  2. Its coordinates satisfy the equation.
  3. Set y = 0 for x-intercepts; set x = 0 for y-intercepts.
  4. d=(x2−x1)2+(y2−y1)2.
  5. ((x1+x2)/2,(y1+y2)/2).

Example problems

Example 1

Find the intercepts of 2x + 3y = 12.

Show solution
  1. At y = 0, 2x = 12 gives (6, 0).
  2. At x = 0, 3y = 12 gives (0, 4).

Example 2

Find distance and midpoint between (−1, 2) and (3, 5).

Show solution
  1. Coordinate differences are 4 and 3.
  2. Distance: 42+32=5.
  3. Midpoint: ((−1 + 3)/2, (2 + 5)/2) = (1, 3.5).

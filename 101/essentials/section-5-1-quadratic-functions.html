Example problems

Example 1

Find the vertex and minimum of y = x² − 6x + 5.

Show solution
  1. Complete the square: y = (x − 3)² − 4.
  2. Vertex: (3, −4); opens upward.
  3. The minimum value is −4, and the range is [−4, ∞).

Example 2

Find the zeros of y = −(x + 1)² + 9.

Show solution
  1. Set y = 0: (x + 1)² = 9.
  2. Thus x + 1 = ±3, giving x = 2 and −4.
  3. The vertex (−1, 9) lies midway between the two intercepts.

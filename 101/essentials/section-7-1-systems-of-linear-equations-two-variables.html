7.1: Systems of Linear Equations: Two Variables · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is a solution to a two-equation system?
  2. What does substitution do?
  3. What does elimination do?
  4. What does a contradiction after elimination mean?
  5. What do dependent equations represent?
Check short-answer key
  1. An ordered pair satisfying both equations.
  2. Replace a variable with an equal expression.
  3. Combine equations so a variable cancels.
  4. The system is inconsistent and has no solution.
  5. The same line, giving infinitely many solutions.

Example problems

Example 1

Solve 2x + y = 9 and x − y = 3.

Show solution
  1. Add equations: 3x = 12, so x = 4.
  2. Substitute: 4 − y = 3, giving y = 1.
  3. Check: 2(4) + 1 = 9 and 4 − 1 = 3.

Example 2

Classify x + 2y = 4 and 2x + 4y = 8.

Show solution
  1. The second equation is twice the first.
  2. Both represent the same line.
  3. Infinitely many solutions: (4 − 2t, t) for any real t.

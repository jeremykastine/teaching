6.8: Fitting Exponential Models to Data · Essentials

Optional applications

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What data pattern suggests exponential growth?
  2. How does this differ from linear growth?
  3. What is a residual?
  4. Why be cautious with extrapolation?
  5. What transformation linearizes y = abˣ when y > 0?
Check short-answer key
  1. Approximately constant output ratios over equal input steps.
  2. Linear growth has approximately constant differences.
  3. Observed output minus model prediction.
  4. A fitted pattern may not continue beyond the observed data.
  5. ln y = ln a + x ln b.

Example problems

Example 1

Fit an exact exponential model to (0, 3), (1, 6), (2, 12).

Show solution
  1. The initial value is a = 3.
  2. Successive ratios are both 2, so b = 2.
  3. The model is y = 3(2ˣ); it predicts 24 at x = 3.

Example 2

A fitted model predicts 50 when x = 4; the observed value is 46. Find the residual and interpret it.

Show solution
  1. Residual = observed − predicted = 46 − 50 = −4.
  2. The point is 4 output units below the model.
  3. One residual alone does not establish whether an exponential model is appropriate overall.

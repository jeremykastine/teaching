4.2: Modeling with Linear Functions · Essentials

Optional applications

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What pattern suggests a linear model?
  2. What does the intercept represent in a cost model?
  3. Why state units for slope?
  4. What is a break-even point?
  5. Why can a model's practical domain be smaller than all real numbers?
Check short-answer key
  1. Equal changes in input produce equal changes in output.
  2. The initial or fixed cost, if input zero is meaningful.
  3. Slope is output units per input unit.
  4. An input at which revenue equals cost, or two compared costs are equal.
  5. Negative inputs or fractional item counts may be meaningless.

Example problems

Example 1

A plan costs $12 plus $4 per visit. Write its model and find the cost for five visits.

Show solution
  1. For nonnegative whole-number v, C(v) = 12 + 4v dollars.
  2. C(5) = 12 + 20 = $32.

Example 2

Compare A(x) = 10 + 3x and B(x) = 22 + x. Where do costs match?

Show solution
  1. Set 10 + 3x = 22 + x.
  2. Solve 2x = 12, giving x = 6.
  3. Both costs are $28; below 6, A is cheaper, and above 6, B is cheaper.

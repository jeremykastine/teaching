3.6: Absolute Value Functions · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does absolute value measure?
  2. What shape is the graph of y = |x|?
  3. Where is the vertex of y=a|x−h|+k?
  4. When does a|x−h|+k open downward?
  5. How many solutions can |u| = c have when c > 0?
Check short-answer key
  1. Distance from zero.
  2. A V with vertex at (0, 0).
  3. (h, k).
  4. When a < 0.
  5. It produces the two cases u = c and u = −c; actual input solutions depend on u.

Example problems

Example 1

Describe y = 2|x − 1| − 3 and find its zeros.

Show solution
  1. Vertex: (1, −3); opens upward with vertical stretch 2.
  2. Set y = 0: |x − 1| = 3/2.
  3. Thus x = 1 ± 3/2, giving −1/2 and 5/2.

Example 2

Solve |2x + 1| = 7.

Show solution
  1. The two cases are 2x + 1 = 7 and 2x + 1 = −7.
  2. They give x = 3 and x = −4.
  3. Each makes the absolute value 7.

Example problems

Example 1

Find the inverse of f(x) = 3x − 5.

Show solution
  1. Write y = 3x − 5, swap x and y: x = 3y − 5.
  2. Solve: y = (x + 5)/3.
  3. Thus f−1(x)=(x+5)/3; substituting into f gives x.

Example 2

Find the inverse of y = x² on x ≥ 0.

Show solution
  1. Swap coordinates: x = y².
  2. The original domain requires the inverse output y ≥ 0, so choose y = √x.
  3. The inverse has domain [0, ∞) and range [0, ∞).

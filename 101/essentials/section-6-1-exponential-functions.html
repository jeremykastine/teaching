Essential facts, definitions, and procedures

  1. What is the basic exponential form?
  2. Which base values produce growth for a > 0?
  3. Which produce decay for a > 0?
  4. How does a constant percent change appear in an exponential model?
  5. What is the compound-interest formula?
Check short-answer key
  1. f(x) = abˣ, with b > 0 and b ≠ 1.
  2. b > 1.
  3. 0 < b < 1.
  4. The output multiplies by the same factor for each equal input step.
  5. A=P(1+r/n)nt, with annual decimal rate r and n compoundings per year.

Example problems

Example 1

For f(x) = 5(2ˣ), find f(0), f(3), and the growth factor.

Show solution
  1. f(0) = 5 and f(3) = 5 × 8 = 40.
  2. Each increase of 1 in x multiplies the output by 2.

Example 2

A quantity starts at 200 and decreases 10% per step. Find its value after two steps.

Show solution
  1. The multiplier is 1 − 0.10 = 0.9.
  2. Model: A(t) = 200(0.9)ᵗ.
  3. A(2) = 200 × 0.81 = 162.

Essential facts, definitions, and procedures

  5. What does a negative discriminant imply about real roots?
Check short-answer key
  1. ax2+bx+c=0, a ≠ 0.
  2. After writing a product equal to zero.
  3. Both signs, when the isolated square equals a positive number.
  4. x=(−b±b2−4ac)/(2a).

Example problems

Example 1

Solve x2−7x+12=0.

Show solution
  1. Factor: (x − 3)(x − 4) = 0.
  2. Set each factor to zero: x = 3 or 4.

Example 2

Solve 2x2−3x−2=0 using the quadratic formula.

Show solution
  1. Use a = 2, b = −3, c = −2; the discriminant is 9 + 16 = 25.
  2. x=(3±5)/4.
  3. Thus x = 2 or −1/2.

Example 3

Solve (x+1)2=12.

Show solution
  1. Take both square roots: x+1=±23.
  2. Subtract 1: x=−1±23.

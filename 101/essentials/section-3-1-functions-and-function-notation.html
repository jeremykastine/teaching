3.1: Functions and Function Notation · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is a function?
  2. What does f(a) mean?
  3. What is the vertical line test?
  4. What is a one-to-one function?
  5. How does evaluating f(a) differ from solving f(x) = a?
Check short-answer key
  1. A rule assigning exactly one output to each input in its domain.
  2. The output of f at input a.
  3. A graph represents a function if no vertical line intersects it more than once.
  4. A function whose distinct inputs have distinct outputs.
  5. Evaluation finds an output; solving finds inputs producing the specified output.

Example problems

Example 1

For f(x) = 2x − 3, find f(4), then solve f(x) = 7.

Show solution
  1. Evaluation: f(4) = 8 − 3 = 5.
  2. Solving: 2x − 3 = 7 gives x = 5.
  3. These are different tasks: an output of 5 versus an input of 5.

Example 2

Does {(1, 2), (2, 3), (1, 4)} define a function?

Show solution
  1. Input 1 is paired with both 2 and 4.
  2. A function allows exactly one output for each input.
  3. Therefore this relation is not a function.

Essential facts, definitions, and procedures

  1. What is a linear equation in one variable?
  2. What operations preserve equality?
  3. How do you clear fixed numerical denominators?
  4. What does a true statement after variables cancel indicate?
  5. What does a false statement after variables cancel indicate?
Check short-answer key
  1. An equation reducible to ax + b = 0, with a ≠ 0.
  2. Adding the same quantity or multiplying by the same nonzero quantity on both sides.
  3. Multiply every term by an LCD.
  4. An identity on the original allowed domain.
  5. No solution.

Example problems

Example 1

Solve 3(2x − 1) = 4x + 9.

Show solution
  1. Distribute: 6x − 3 = 4x + 9.
  2. Subtract 4x and add 3: 2x = 12, giving x = 6.
  3. Both original sides equal 33.

Example 2

Solve (x − 2)/3 + 1/2 = 5/6.

Show solution
  1. Multiply every term by 6: 2(x − 2) + 3 = 5.
  2. Simplify: 2x − 1 = 5, so x = 3.
  3. Check: 1/3 + 1/2 = 5/6.

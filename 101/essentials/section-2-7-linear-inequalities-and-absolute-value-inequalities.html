Essential facts, definitions, and procedures

  1. When must an inequality symbol reverse?
  2. What do interval parentheses mean?
  3. What do interval brackets mean?
  4. What does AND mean for solution sets?
  5. For c > 0, what does |x|<c mean?
Check short-answer key
  1. When multiplying or dividing both sides by a negative number.
  2. The endpoint is excluded.
  3. A finite endpoint is included.
  4. Intersection: both conditions must hold.
  5. −c < x < c.

Example problems

Example 1

Solve −3x + 2 ≥ 11.

Show solution
  1. Subtract 2: −3x ≥ 9.
  2. Divide by −3 and reverse: x ≤ −3.
  3. Interval: (−∞,−3].

Example 2

Solve |x−2|<5.

Show solution
  1. Rewrite as −5 < x − 2 < 5.
  2. Add 2 throughout: −3 < x < 7.
  3. Interval: (−3, 7).

3.1B: Function Notation as Abbreviation · Essentials

Supplemental lesson

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does defining f(x) as an expression let you do?
  2. What must be replaced when evaluating f(−2)?
  3. Does f(x) mean f multiplied by x?
  4. If f(x) replaces part of a longer expression, what stays unchanged?
  5. Can two functions of x be used in the same expression?
Check short-answer key
  1. Use f(x) as an abbreviation for the entire expression.
  2. Every occurrence of x in f's defining expression.
  3. No; it denotes a function's output at input x.
  4. All parts not included in f's definition.
  5. Yes; each abbreviation retains its own definition.

Example problems

Example 1

Let f(x) = x² + 3x − 1. Rewrite x² + 3x − 1 + 4x, then evaluate at x = 2.

Show solution
  1. The rewrite is f(x) + 4x.
  2. f(2) = 4 + 6 − 1 = 9.
  3. The full value is 9 + 8 = 17.

Example 2

Let f(x) = 2x + 1 and g(x) = x² − 4. Rewrite 3(2x + 1) − (x² − 4) + x.

Show solution
  1. Replace the defined pieces: 3f(x) − g(x) + x.
  2. At x = 1, f(1) = 3 and g(1) = −3.
  3. The value is 3(3) − (−3) + 1 = 13.

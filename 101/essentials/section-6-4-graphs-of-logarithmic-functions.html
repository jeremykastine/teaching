6.4: Graphs of Logarithmic Functions · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is the domain of y = log base b of x?
  2. What is its range?
  3. What is its vertical asymptote?
  4. Where does the basic logarithmic graph cross the x-axis?
  5. For y = log base b of (x − h) + k, what gives the domain?
Check short-answer key
  1. (0, ∞).
  2. All real numbers.
  3. x = 0.
  4. (1, 0).
  5. x − h > 0, so x > h.

Example problems

Example 1

Analyze y = log₂(x − 3) + 1.

Show solution
  1. Shift the basic log₂ graph right 3 and up 1.
  2. Domain: (3, ∞); range: all real numbers; asymptote: x = 3.
  3. Since log₂1 = 0, the point (4, 1) lies on the graph.

Example 2

Find the intercept and asymptote of y = ln(x + 2).

Show solution
  1. Require x + 2 > 0, giving domain (−2, ∞) and asymptote x = −2.
  2. For y = 0, x + 2 = 1, so the x-intercept is (−1, 0).
  3. At x = 0, the y-intercept is (0, ln 2).

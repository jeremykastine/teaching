7.3: Systems of Nonlinear Equations and Inequalities: Two Variables · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What makes a system nonlinear?
  2. What do intersections of the graphs represent?
  3. How can substitution solve a line-parabola system?
  4. When is an inequality boundary included?
  5. How do you combine inequalities in a system?
Check short-answer key
  1. At least one equation is nonlinear.
  2. Ordered pairs solving every equation.
  3. Substitute the line's expression for y into the parabola's equation.
  4. For ≤ or ≥, use a solid boundary; for < or >, exclude it.
  5. Take the overlap of their solution regions.

Example problems

Example 1

Solve y = x² and y = x + 2.

Show solution
  1. Set x² = x + 2, so (x − 2)(x + 1) = 0.
  2. Inputs are 2 and −1.
  3. Substitute to get intersections (2, 4) and (−1, 1).

Example 2

Describe the region satisfying y ≥ x² and y ≤ 4.

Show solution
  1. Include both boundaries because both inequalities are inclusive.
  2. Shade above the parabola and below the horizontal line.
  3. They meet where x² = 4, at x = ±2; the shared region has −2 ≤ x ≤ 2 and x² ≤ y ≤ 4.

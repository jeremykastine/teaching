Example problems

Example 1

Evaluate log232 and log3(1/9).

Show solution
  1. Since 2⁵ = 32, the first value is 5.
  2. Since 3⁻² = 1/9, the second value is −2.

Example 2

Rewrite log5125=3 exponentially and evaluate ln(e²).

Show solution
  1. The logarithmic statement says 5³ = 125.
  2. The inverse relationship gives ln(e²) = 2.

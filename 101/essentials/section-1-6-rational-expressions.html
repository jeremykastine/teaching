Essential facts, definitions, and procedures

  1. What values are excluded from a rational expression?
  2. What may be canceled in a fraction?
  3. How do you divide rational expressions?
  4. What is required before adding rational expressions?
  5. Do exclusions disappear after cancellation?
Check short-answer key
  1. Values making any original denominator zero.
  2. Common nonzero factors of numerator and denominator.
  3. Multiply by the reciprocal, requiring the divisor to be defined and nonzero.
  4. A common denominator.
  5. No; original restrictions remain.

Example problems

Example 1

Simplify (x2−4)/(x2+x−6).

Show solution
  1. Factor: (x−2)(x+2)/((x+3)(x−2)).
  2. Original restrictions: x ≠ −3, 2.
  3. Cancel x − 2 to get (x + 2)/(x + 3), retaining both restrictions.

Example 2

Add 1/x+2/(x+1).

Show solution
  1. Require x ≠ 0, −1; use LCD x(x + 1).
  2. Combine numerators: x + 1 + 2x = 3x + 1.
  3. Result: (3x+1)/(x(x+1)).

6.6: Exponential and Logarithmic Equations · Essentials

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. How can an exponential equation be solved when both sides have the same valid base?
  2. How can logarithms solve an exponential equation?
  3. How do you solve log base b of u = c?
  4. Why check logarithmic-equation candidates?
  5. Can a positive-base exponential equal a negative number?
Check short-answer key
  1. Equate the exponents.
  2. Isolate the exponential, take a logarithm, and use the power rule.
  3. Rewrite as u = bᶜ, retaining u > 0.
  4. The original logarithm arguments must all be positive.
  5. No.

Example problems

Example 1

Solve 32x−1=27.

Show solution
  1. Write 27 as 3³.
  2. Equate exponents: 2x − 1 = 3.
  3. Thus x = 2.

Example 2

Solve ln(x−1)+ln(x+1)=ln8.

Show solution
  1. The original domain requires x > 1.
  2. Combine and equate positive arguments: (x − 1)(x + 1) = 8.
  3. Then x² = 9 gives ±3, but only x = 3 meets the original domain.

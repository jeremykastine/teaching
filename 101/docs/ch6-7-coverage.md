## Prompt sequencing decisions

- Exponential ratios and logarithmic inverse operations are established before equations or applied thresholds.
- Logarithmic domain checks appear first in definitions, then graphing, then property use, and finally equations. They supplement the textbook emphasis without turning every problem into a domain drill.
- Standard algebraic techniques remain central: substitution, factoring, exact arithmetic, and equation verification carry across chapters.
- Transformed curves are treated as functions before model parameters acquire real-world units. The annotation space is reserved for the instructor's graph sketches and derivations.
- Applications and regression prompts use original values and examples. No classroom solution or explanatory narration is embedded in a slide.
- Nonlinear inequalities receive a complete sequence after equation intersections: boundary, membership, side, common shading, and feasible regions. Chapter 7.3 is not limited to nonlinear equations.

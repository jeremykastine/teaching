3.1B: Why Function Notation? Abbreviating Repeated Calculations

A long expression can repeat the same calculation with different inputs. Instead of writing that calculation again and again, we can give it a short name such as f. The parentheses in f(3) tell us which number to substitute into the named calculation.

For every problem: Identify the calculation that repeats, define a function (or functions) for it, and rewrite the entire expression using function notation. Leave any unrelated terms outside the function notation. Do not evaluate or simplify.

Double-click or double-tap the blank solution area to reveal or hide the answer. Keyboard users can press Enter or Space. Long expressions scroll horizontally; they never wrap.

Easy: Recognize one repeated calculation

Start with three evaluations. Notice that the input changes while the instructions stay the same.

Problem 1

2(3)+5+2(7)+5+2(10)+5

Define: f(t)=2t+5

Rewrite: f(3)+f(7)+f(10)

Problem 2

3(2)^2-4(2)+7+3(5)^2-4(5)+7+3(9)^2-4(9)+7

Define: f(t)=3t²−4t+7

Rewrite: f(2)+f(5)+f(9)

Problem 3

4(1)^2+2(1)-3+4(6)^2+2(6)-3-4(8)^2-2(8)+3

Define: f(t)=4t²+2t−3

Rewrite: f(1)+f(6)−f(8)

Medium: Coefficients and unrelated terms

Problem 4

5(2²+3(2)+2)-3(4²+3(4)+2)+7²+3(7)+2

Define: f(t)=t²+3t+2

Rewrite: 5f(2)−3f(4)+f(7)

Problem 5

2(3)^2-3+6+11+2(5)^2-5+6-2(8)^2+8-6

Define: f(t)=2t²−t+6

Rewrite: f(3)+11+f(5)−f(8)

Problem 6

3((x+1)²+2(x+1)-4)+7x-2((x+3)²+2(x+3)-4)+9+(2²+2(2)-4)

Define: f(t)=t²+2t−4

Rewrite: 3f(x+1)+7x−2f(x+3)+9+f(2)

Problem 7

4(2(x+2)²-3(x+2)+1)-5x+2(2(3)²-3(3)+1)-7(2(x-1)²-3(x-1)+1)+6

Define: f(t)=2t²−3t+1

Rewrite: 4f(x+2)−5x+2f(3)−7f(x−1)+6

Hard: Two repeated calculations

Look for two distinct repeated patterns. Give each its own name.

Problem 8

2²+2(2)+1+3(5)-4+7²+2(7)+1-3(3)+4

Define: f(t)=t²+2t+1; g(t)=3t−4

Rewrite: f(2)+g(5)+f(7)−g(3)

Problem 9

3(2(4)²+3(4)-5)-2(6³-4(6)+1)+2(7)²+3(7)-5+9-(3³-4(3)+1)

Define: f(t)=2t²+3t−5; g(t)=t³−4t+1

Rewrite: 3f(4)−2g(6)+f(7)+9−g(3)

Problem 10

4((x+1)²-3(x+1)+8)-3((2x)³+4(2x)-5)+6x²+((x-1)³+4(x-1)-5)-2((3x)²-3(3x)+8)+11

Define: f(t)=t²−3t+8; g(t)=t³+4t−5

Rewrite: 4f(x+1)−3g(2x)+6x²+g(x−1)−2f(3x)+11

Challenge: Large expressions, short descriptions

Problem 11

2(3(x+1)²-2(x+1)+7)-5((2x)³+4(2x)-6)+3x²+((x-3)³+4(x-3)-6)-4(3(2x-1)²-2(2x-1)+7)+9+3(5)²-2(5)+7-2((x+4)³+4(x+4)-6)

Define: f(t)=3t²−2t+7; g(t)=t³+4t−6

Rewrite: 2f(x+1)−5g(2x)+3x²+g(x−3)−4f(2x−1)+9+f(5)−2g(x+4)

Problem 12

5(3(x+2)²+4(x+2)-7)-2(2(3x-1)³-(3x-1)+5)+4x²-7x+3(2(x+3)³-(x+3)+5)-6(3(2x-3)²+4(2x-3)-7)+11x-8+2(3(x-2)²+4(x-2)-7)-(2(4x+1)³-(4x+1)+5)+9

Define: f(t)=3t²+4t−7; g(t)=2t³−t+5

Rewrite: 5f(x+2)−2g(3x−1)+4x²−7x+3g(x+3)−6f(2x−3)+11x−8+2f(x−2)−g(4x+1)+9

Different correct choices of function names are possible. Check your work by replacing each function evaluation with its defining calculation; the original expression should reappear exactly. The symbol t inside a definition is only a placeholder for the input, not an additional variable in the original expression.

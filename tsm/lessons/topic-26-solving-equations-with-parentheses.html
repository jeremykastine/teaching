Topic 26: Solving Equations with Parentheses

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic solves linear equations containing parentheses by distributing first and then collecting and isolating terms.

Key definitions

Distributive property: multiplication of an outside factor by every term in parentheses. Like terms: terms with identical variable parts. Equivalent equation: an equation with the same solutions as the original.

Solve

\[3x + 1 = - (x - 13).\]

Parentheses signal multiplication. Distribute the factor to every term inside the parentheses, including a negative sign.

The negative sign means multiplication by \(- 1\).

\[3x + 1 = - x + 13.\]

Add \(x\), subtract \(1\), and divide by \(4\).

\[4x = 12\]

\[x = 3.\]

A number distributed on both sides

\[7(x + 4) = 9(x - 2)\]

Distribute.

\[7x + 28 = 9x - 18.\]

Move the variable terms and constants.

\[46 = 2x\]

\[x = 23.\]

Subtracting a parenthesized expression

In \(- (4y + 3) - ( - 3y - 4) = 0\), each leading subtraction changes both signs in the following parentheses.

\[- 4y - 3 + 3y + 4 = 0\]

\[- y + 1 = 0\]

\[y = 1.\]

A common error is to change only the first sign inside a subtracted group. Write the distributed line explicitly to prevent that mistake.

Decimal coefficients

Decimals do not change the algebra. For \(0.30(12) + 0.05x = 0.10(18 + x)\), distribute, combine, and solve exactly as with integers. You may multiply the entire equation by \(100\) first if that makes the arithmetic clearer.

Solve and check: \(4(x - 5) = 2x + 6\), \(- 2(3m - 1) + 5 = 4m - 7\), and \(3 - (2y - 5) = 2(y + 1)\).

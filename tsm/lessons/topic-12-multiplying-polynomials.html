TSM Lecture Notes

Topic 12: Multiplying Polynomials

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic multiplies polynomial expressions by forming every required pairwise product and then combining like terms.

Key definitions

Polynomial: a sum of terms with whole-number variable exponents. Monomial, binomial, and trinomial: polynomials with one, two, and three terms. FOIL: an organizational name for the four products formed by two binomials.

Expand and simplify.

\((x\ - \ 7)(x\ - \ 6)\)

The first factor contains x and negative 7. Begin with x from the first factor: it multiplies both x and negative 6 in the second factor. Then negative 7 must also multiply both terms in the second factor. This produces four products, not just two.

\(x^{2}\ - \ 6x\ - \ 7x\ + \ 42\)

After all four products have been written, combine the two x-terms. Six negative copies of x and seven more negative copies make thirteen negative copies.

\(x^{2}\ - \ 13x\ + \ 42\)

Multiplying polynomials extends the distributive property from B5. Each polynomial inside parentheses is a factor. Every term in one factor must multiply every term in the other factor. Keep the sign attached to each term, simplify every individual product, and then combine like terms. Each displayed line must remain equivalent to the original product.

Expand and simplify using FOIL.

\((7z\ - \ u)(2z\ + \ 5u)\)

When both factors are binomials, the four products can be remembered with the word FOIL: First, Outer, Inner, Last. FOIL is not a different property; it is an order for carrying out the distributive property when each factor contains exactly two terms.

The first terms give 14z squared. The outer terms give 35zu. The inner terms give negative 2uz, which may be written as negative 2zu because the order of multiplied factors can be rearranged. The last terms give negative 5u squared.

\(14z^{2}\ + \ 35zu\ - \ 2zu\ - \ 5u^{2}\)

The middle products are like terms because both contain one z-factor and one u-factor. Thirty-five positive copies and two negative copies leave thirty-three positive copies.

\(14z^{2}\ + \ 33zu\ - \ 5u^{2}\)

Expand and simplify.

\((5t\ - \ 2)(5t\ + \ 2)\)

FOIL produces two middle terms that are opposites.

\(25t^{2}\ + \ 10t\ - \ 10t\ - \ 4\)

Ten positive copies of t and ten negative copies of t cancel in pairs, leaving no t-term. A zero t-term does not need to be written.

\(25t^{2}\ - \ 4\)

Find the product using FOIL.

\((8z\ + \ 5)(8z\ + \ 2)\)

\(64z^{2}\ + \ 16z\ + \ 40z\ + \ 10\)

\(64z^{2}\ + \ 56z\ + \ 10\)

Use the FOIL method to find the product.

\((3z\ - \ u)(3z\ + \ 7u)\)

\(9z^{2}\ + \ 21zu\ - \ 3zu\ - \ 7u^{2}\)

\(9z^{2}\ + \ 18zu\ - \ 7u^{2}\)

Multiply.

\((5t\ - \ 4)(5t\ + \ 4)\)

\(25t^{2}\ + \ 20t\ - \ 20t\ - \ 16\)

\(25t^{2}\ - \ 16\)

Expand and simplify.

\((8x\ + \ 1)(9x^{2}\ + \ 3x\ + \ 1)\)

FOIL lists four products because a binomial has two terms and another binomial has two terms. When a factor has three or more terms, use the distributive property directly. A factor with two terms multiplied by a factor with three terms must produce six individual products.

First, 8x multiplies all three terms in the second factor. Then positive 1 multiplies all three terms. Do not move on to combining like terms until all six products are present.

\(72x^{3}\ + \ 24x^{2}\ + \ 8x\ + \ 9x^{2}\ + \ 3x\ + \ 1\)

Now combine terms having exactly the same variable part.

\(72x^{3}\ + \ 33x^{2}\ + \ 11x\ + \ 1\)

Multiply.

\((6x\ + \ 2)(4x^{2}\ + \ 4x\ + \ 7)\)

\(24x^{3}\ + \ 24x^{2}\ + \ 42x\ + \ 8x^{2}\ + \ 8x\ + \ 14\)

\(24x^{3}\ + \ 32x^{2}\ + \ 50x\ + \ 14\)

Multiply.

\((x^{3}\ + \ x^{2}\ + \ x\ + \ 1)(12x\ - \ 7)\)

Four terms multiplied by two terms produce eight products.

\(12x^{4}\ - \ 7x^{3}\ + \ 12x^{3}\ - \ 7x^{2}\ + \ 12x^{2}\ - \ 7x\ + \ 12x\ - \ 7\)

\(12x^{4}\ + \ 5x^{3}\ + \ 5x^{2}\ + \ 5x\ - \ 7\)

Expand and simplify.

\((5t^{2}\ - \ t\ - \ 3)(3t^{2}\ + \ 5t\ - \ 1)\)

Use each of the three terms in the first factor with all three terms in the second factor. The sign belongs to the term: the second term is negative t, and the third term is negative 3. Three terms times three terms gives nine products.

\(15t^{4}\ + \ 25t^{3}\ - \ 5t^{2}\ - \ 3t^{3}\ - \ 5t^{2}\ + \ t\ - \ 9t^{2}\ - \ 15t\ + \ 3\)

Collect the terms with the same power of t. The t-cubed terms combine, the three t-squared terms combine, and the two t-terms combine.

\(15t^{4}\ + \ 22t^{3}\ - \ 19t^{2}\ - \ 14t\ + \ 3\)

Expand and simplify.

\(4y^{2}(4y\ + \ 1)(y\ - \ 2)\)

A product can contain more than two factors. The associative property allows us to choose two factors, replace them with their product, and then multiply by the remaining factor. This is like evaluating 2 times 3 times 4 by first finding 2 times 3 and then multiplying the result by 4.

First multiply the monomial 4y squared by the binomial 4y plus 1. Keep the remaining factor in place.

\((16y^{3}\ + \ 4y^{2})(y\ - \ 2)\)

Now multiply the two resulting binomials and combine the like y-cubed terms.

\(16y^{4}\ - \ 32y^{3}\ + \ 4y^{3}\ - \ 8y^{2}\)

\(16y^{4}\ - \ 28y^{3}\ - \ 8y^{2}\)

Find the product.

\(3y^{4}(3y\ + \ 5)(y\ - \ 3)\)

Multiply the first two factors, then multiply the result by the last factor.

\((9y^{5}\ + \ 15y^{4})(y\ - \ 3)\)

\(9y^{6}\ - \ 27y^{5}\ + \ 15y^{5}\ - \ 45y^{4}\)

\(9y^{6}\ - \ 12y^{5}\ - \ 45y^{4}\)

To multiply polynomials, make sure every term in one factor is paired with every term in the other factor. FOIL is a convenient four-product checklist only for a binomial times a binomial; longer polynomials require the same distributive idea without the FOIL label. Keep signs attached to terms, use the product rule when variable factors are multiplied, and wait until every product has been written before combining like terms. With three or more factors, multiply two factors at a time and then continue with the remaining factor.

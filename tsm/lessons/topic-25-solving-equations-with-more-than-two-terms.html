Topic 25: Solving Equations with More Than Two Terms

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic solves longer linear equations by simplifying each side, moving variable and constant terms, and identifying special outcomes.

Key definitions

Equivalent equations: equations with the same solution set. No solution: no value makes the equation true. All real numbers: every real value makes the equation true.

Solving a multi-step linear equation

For a multi-step linear equation, first simplify each side by combining like terms. Then move variable terms to one side, move constants to the other side, and divide by the remaining coefficient.

Solve

\[7x + 4 = 5x + 14.\]

Subtract \(5x\) from both sides.

\[2x + 4 = 14.\]

Subtract \(4\), then divide by \(2\).

\[2x = 10\]

\[x = 5.\]

Substitution gives \(39 = 39\), so the answer checks.

Solve for x. Combine like terms on each side first.

\[7x-4-2x+9+x=3x+8+x-5+6\]

Combine the variable terms and the constants on each side.

\[6x+5=4x+9\]

Subtract the same variable term and constant from both sides, then divide.

\[2x=4\qquad\Rightarrow\qquad x=2\]

Check by substituting \(x=2\) in the original equation. The left side is \(14-4-4+9+2=17\), and the right side is \(6+8+2-5+6=17\).

When the variable terms cancel

If simplification removes every variable term, inspect the remaining statement. A true statement means every real number is a solution; a false statement means no solution. Do not divide by zero to force a numerical answer.

Solve for x.

\[6-4x=7x-9x+2\]

\[6 - 4x = 7x - 9x + 2\]

The right side simplifies to \(- 2x + 2\).

\[6 - 4x = - 2x + 2\]

\[4 = 2x\]

\[x = 2.\]

Solve \(3x-4+2x=1+5x-5\). State whether there is one solution, no solution, or all real numbers are solutions.

Both sides simplify to \(5x - 4\), so the final statement is \(- 4 = - 4\), which is always true. Every real number is a solution.

Solve and check \(8x-9=11x+12\).

Use the same operation on both sides to isolate the variable.

\[-21=3x\quad\Rightarrow\quad x=-7\]

Check in the original equation (\(8(-7)-9=-65=11(-7)+12\)).

Solve and check \(5-3y=2y+20\).

Use the same operation on both sides to isolate the variable.

\[-15=5y\quad\Rightarrow\quad y=-3\]

Check in the original equation (\(5-3(-3)=14=2(-3)+20\)).

Solve \(4a+7-2a=2a+7\).

Combine like terms on the left.

\[2a+7=2a+7\]

Both sides are identical for every real a, so all real numbers are solutions.

Solve \(9m-2=9m+6\).

Subtract 9m from both sides.

\[-2=6\]

The statement is false, so there is no solution.

Solve for x. Combine like terms on each side first.

\[8-3x+5-2x-6+x=4x-7-3x+12-5x-1\]

Combine the variable terms and the constants on each side.

\[-4x+7=-4x+4\]

Add \(4x\) to both sides.

\[7=4\]

The resulting statement is false, so there is no solution.

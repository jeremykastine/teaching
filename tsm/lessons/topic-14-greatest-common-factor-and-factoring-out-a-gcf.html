Topic 14: Greatest Common Factor and Factoring Out a GCF

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic finds the greatest factor shared by every term of a polynomial and rewrites the polynomial as a product.

Key definitions

Greatest common factor (GCF): the largest numerical and variable factor common to all terms. Factoring: rewriting a sum or difference as a product. Factored form: an equivalent expression written as multiplication.

Find the greatest common factor (GCF).

\(20x,\ 45\)

The variable x is not contained in 45, so x is not a common factor. For the numerical parts, 5 is the greatest number that divides both 20 and 45.

\(GCF\ = \ 5\)

Factoring out a greatest common factor reverses the distributive property. Instead of starting with one factor outside parentheses and distributing it to several terms, we begin with several terms, identify the largest factor contained in every term, and write that common factor once outside parentheses. The factors left from the individual terms are written inside the parentheses. Multiplying the result should reproduce the original expression.

Find the greatest common factor for the list of terms.

\(110x^{3},\ 70x^{4},\ 60x^{7}\)

First find the numerical GCF. The greatest number dividing 110, 70, and 60 is 10. Then compare the x-factors. The terms contain three, four, and seven copies of x. Only three copies occur in every term, so the common variable factor is x cubed.

\(GCF\ = \ 10x^{3}\)

The smallest exponent is used because it records the number of copies that all of the terms share. A factor containing x to the fourth could not divide the first term, which contains only three x-factors.

Find the greatest common factor for the list of terms.

\(a^{3}b,\ - ab^{4},\ a^{5}b,\ b^{3}\)

Every term contains at least one b-factor, so b is common. The letter a appears in the first three terms but not in the last term. Because a is missing from one term, it cannot be part of the GCF.

\(GCF\ = \ b\)

Find the greatest common factor.

\(a^{3}b,\ - ab^{2}\)

Both terms contain one a-factor and one b-factor.

\(GCF\ = \ ab\)

Find the greatest common factor.

\(10m^{5},\ 40m^{9}\)

The numerical GCF is 10, and the smaller m-exponent is 5.

\(GCF\ = \ 10m^{5}\)

Find the greatest common factor.

\(64a^{9}b^{2},\ 40a^{6}b^{9}\)

The numerical GCF is 8. The shared variable factors use the smaller exponent for each letter: a to the sixth and b squared.

\(GCF\ = \ 8a^{6}b^{2}\)

Complete the factoring.

\(- 21x^{7}y^{5}\ = \ 7x^{5}y\ \cdot \ (\ ?\ )\)

When one factor is already shown, determine what must multiply it to recreate the original monomial. Divide the numerical parts and compare the repeated variable factors. Equivalently, subtract the exponent already shown from the exponent in the original term.

The coefficient must be negative 3. Five of the seven x-factors are already outside, leaving two. One of the five y-factors is already outside, leaving four.

\(- 21x^{7}y^{5}\ = \ 7x^{5}y( - 3x^{2}y^{4})\)

Complete the factoring.

\(- 25x^{4}y^{6}z^{2}\ = \ - 5x^{2}yz\ \cdot \ (\ ?\ )\)

The two negative factors require a positive missing factor. Dividing the coefficients gives 5. The remaining variable factors are x squared, y to the fifth, and z.

\(- 25x^{4}y^{6}z^{2}\ = \ - 5x^{2}yz(5x^{2}y^{5}z)\)

Complete the factoring.

\(49x^{6}\ = \ 7x^{4}\ \cdot \ (\ ?\ )\)

\(49x^{6}\ = \ 7x^{4}(7x^{2})\)

Complete the factoring.

\(- 30x^{5}y^{5}z^{2}\ = \ - 3x^{3}yz\ \cdot \ (\ ?\ )\)

\(- 30x^{5}y^{5}z^{2}\ = \ - 3x^{3}yz(10x^{2}y^{4}z)\)

Factor out the greatest common factor.

\(9s^{2}\ + \ 3s\)

The greatest common factor is 3s. Rewrite each term as a product containing 3s. The first term has 3s left after the GCF is removed; the second term has 1 left. The 1 must be written so that distributing 3s recreates the term 3s.

\(3s\ \cdot \ 3s\ + \ 3s\ \cdot \ 1\)

\(3s(3s\ + \ 1)\)

A quick check is to distribute 3s back through the parentheses. The products are 9s squared and 3s, exactly the original terms.

Factor out the greatest common factor. Check by multiplying.

\(3x^{6}\ - \ 21x^{4}\)

Both terms contain 3 and at least four x-factors, so the GCF is 3x to the fourth. Removing that factor leaves x squared from the first term and negative 7 from the second.

\(3x^{4}\ \cdot \ x^{2}\ - \ 3x^{4}\ \cdot \ 7\)

\(3x^{4}(x^{2}\ - \ 7)\)

Using a smaller common factor would produce an equivalent expression, but it would not complete the instruction to factor out the greatest common factor.

Factor. Check by multiplying.

\(x^{2}\ - \ 8x\)

\(x(x\ - \ 8)\)

Factor. Check by multiplying.

\(8x^{9}\ - \ 48x^{7}\)

\(8x^{7}(x^{2}\ - \ 6)\)

Factor out the greatest common factor.

\(11y^{4}\ - \ 25\)

The coefficients 11 and 25 have no common factor greater than 1, and the second term contains no y-factor. Writing 1 outside parentheses would not change the expression.

\(1(11y^{4}\ - \ 25)\)

Therefore, there is no nontrivial common factor to remove. In ordinary factored form, the expression remains unchanged.

\(11y^{4}\ - \ 25\)

Factor out the greatest common factor.

\(45x^{3}\ - \ 36x^{2}\ + \ 9x\)

The numerical GCF of 45, 36, and 9 is 9. Every term contains at least one x-factor, so the complete GCF is 9x. Divide each term by 9x to determine the three terms inside the parentheses.

\(9x\ \cdot \ 5x^{2}\ - \ 9x\ \cdot \ 4x\ + \ 9x\ \cdot \ 1\)

\(9x(5x^{2}\ - \ 4x\ + \ 1)\)

Factor out the greatest common factor. Check by multiplying.

\(6x^{9}y^{7}\ + \ 42x^{7}y^{6}\ + \ 12xy\)

The coefficients share 6. The smallest x-exponent and the smallest y-exponent are both 1 because the final term contains only one copy of each variable. Thus the GCF is 6xy.

\(6xy(x^{8}y^{6}\ + \ 7x^{6}y^{5}\ + \ 2)\)

Factor out the greatest common factor.

\(4m^{2}n^{4}\ + \ 28m^{2}n^{3}\)

\(4m^{2}n^{3}(n\ + \ 7)\)

Factor out the greatest common factor.

\(6x^{7}\ - \ 48x^{6}\ + \ 36x^{5}\)

\(6x^{5}(x^{2}\ - \ 8x\ + \ 6)\)

Factor out the greatest common factor.

\(x(y\ - \ 5)\ + \ t(y\ - \ 5)\)

A factor does not have to be a single number or variable. An entire expression in parentheses may be one factor. When exactly the same parenthetical factor appears in every term, treat that group as one repeated object and factor it out.

Both terms contain the factor y minus 5. Write that common factor once outside the parentheses. The factors left behind are x and t.

\((y\ - \ 5)(x\ + \ t)\)

Factor out the greatest common factor.

\(a(y\ - \ 3)\ + \ t(y\ - \ 3)\)

The matching factor y minus 3 is the GCF. Removing it from the two terms leaves a and t.

\((y\ - \ 3)(a\ + \ t)\)

Factor.

\(7a^{4}(8a\ - \ 5)\ + \ 6(8a\ - \ 5)\)

The complete group 8a minus 5 appears once in each term. After that factor is removed, the remaining factors are 7a to the fourth and 6.

\((8a\ - \ 5)(7a^{4}\ + \ 6)\)

To factor out a GCF, first identify the greatest numerical factor shared by every term. For each variable that appears in every term, use the smallest exponent because that is the number of repeated factors common to all terms. Write the GCF outside parentheses, divide each original term by it, and place the resulting factors inside. Check by distributing. If the only common factor is 1, there is nothing useful to factor out. The same process applies when the common factor is an entire matching expression in parentheses.

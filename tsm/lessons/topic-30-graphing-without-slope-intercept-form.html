Topic 30: Graphing Without Slope-Intercept Form

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic graphs linear equations that are not already in slope-intercept form by finding intercepts or plotting ordered-pair solutions.

Key definitions

x-intercept: a point where y = 0. y-intercept: a point where x = 0. Ordered pair: coordinates (x, y) that locate a point. Linear equation: an equation whose graph is a line.

Graph \(3x+2y=12\) using its x- and y-intercepts.

For a standard-form equation \(Ax + By = C\), the intercepts are often easy to find. Set \(y = 0\) to find the \(x\)-intercept, and set \(x = 0\) to find the \(y\)-intercept.

\[3x = 12\quad \Rightarrow \quad x = 4.\]

This gives \((4,0)\). For the \(y\)-intercept, set \(x = 0\).

\[2y = 12\quad \Rightarrow \quad y = 6.\]

This gives \((0,6)\). Plot the two points, draw the line through them, and extend it in both directions.

Ordered pairs on a line

An ordered pair \((x,y)\) lies on a graph when its coordinates make the equation true. One way to graph any two-variable linear equation is to choose values for one variable, solve for the other, and plot the resulting points. Two distinct points determine a line; a third point is useful as a check.

Vertical and horizontal lines

The equation \(x = 3\) represents every point whose \(x\)-coordinate is \(3\), so its graph is vertical. The equation \(y = - 2\) represents every point whose \(y\)-coordinate is \(- 2\), so its graph is horizontal.

Check the graph

Select another visible point on the line and substitute it into the original equation. For \(3x + 2y = 12\), the point \((2,3)\) checks because \(3(2) + 2(3) = 12\).

Graph \(2x + 5y = 10\) by intercepts, graph \(x - 2y = 4\) using three ordered pairs, and graph \(x = - 4\) and \(y = 5\). Use a coordinate window from \(- 10\) to \(10\) on each axis.

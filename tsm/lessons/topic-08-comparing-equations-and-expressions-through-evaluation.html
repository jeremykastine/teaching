Topic 8: Comparing Equations and Expressions Through Evaluation

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic evaluates both sides of equations at selected inputs to test solutions and gather evidence about whether two expressions agree.

Key definitions

Expression: numbers, variables, and operations without an equals sign. Equation: a statement that two expressions are equal. Solution: a value that makes an equation true. Identity: an equation true for every allowable input. Restriction: a value excluded from an expression's domain.

Evaluate \(x^2-3x+2\) for \(x=-2\).

An expression represents a value, while an equation states that two expressions are equal. To evaluate an expression, replace every occurrence of the variable with the given number and follow the order of operations. Parentheses around a substituted negative value are essential.

\[( - 2)^{2} - 3( - 2) + 2 = 4 + 6 + 2 = 12.\]

Writing \(- 2^{2}\) instead would mean \(- \left( 2^{2} \right) = - 4\), so the parentheses protect the intended substitution.

Checking whether a value solves an equation

A value is a solution only when the two sides of the equation evaluate to the same number. Check \(x = 3\) in

\[2(x + 4) = 3x + 5.\]

The left side is \(2(3 + 4) = 14\). The right side is \(3(3) + 5 = 14\). Since both sides equal \(14\), \(x = 3\) is a solution.

Now check \(x = 2\). The left side is \(12\), while the right side is \(11\). Since the values differ, \(x = 2\) is not a solution.

One solution is not the same as an identity

If two expressions agree for one tested value, that proves only that the value is a solution of the equation. It does not prove that the expressions are equivalent for every allowable value.

For example, compare \(x^{2}\) and \(2x\). They agree when \(x = 2\), because both equal \(4\), but they do not agree when \(x = 3\). Therefore \(x^{2} = 2x\) is not an identity.

By contrast, \(3(x + 2)\) and \(3x + 6\) agree because the distributive property makes them equivalent. Testing several values can provide evidence, but algebraic reasoning is what proves an identity.

Rational expressions require allowable inputs

Never use a value that makes a denominator zero. For \((x + 1)/(x - 4)\), the input \(x = 4\) is undefined and cannot be used as a test value or a solution.

Evaluate \(2x^{2} - 5x + 1\) at \(x = 3\) and \(x = - 3\). Then test \(x = 1\) and \(x = 4\) in the equation \(x(x + 2) = 3x\), and state exactly what each result proves.

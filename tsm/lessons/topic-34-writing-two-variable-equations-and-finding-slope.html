Topic 34: Writing Two-Variable Equations and Finding Slope

Assigned to: TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic finds slope and writes linear equations from graphs, tables, points, slopes, and intercepts.

Key definitions

Slope: change in y divided by change in x. Point-slope form: y - y1 = m(x - x1). Slope-intercept form: y = mx + b. Rate of change: the constant change in one variable per unit change in another.

Slope

For two points \((x_1,y_1)\) and \((x_2,y_2)\), compute the slope using \(m=\frac{y_2-y_1}{x_2-x_1}\) when \(x_2\ne x_1\). A horizontal line has slope 0. A vertical line has undefined slope because its horizontal change is zero.

Find the slope of the line through \((-2,5)\) and \((4,-1)\).

Subtract the coordinates in the same order in the numerator and denominator.

\[m = \frac{- 1 - 5}{4 - ( - 2)} = \frac{- 6}{6} = - 1.\]

Point-slope form

Point-slope form is \(y-y_1=m(x-x_1)\).

Other ways to obtain the line

First compute the slope, then use either point in point-slope form. Finally substitute the other point to check the equation.

In a table for a linear relationship, equal changes in \(x\) produce equal changes in \(y\). The ratio of those changes is the slope. On a graph, choose two clearly countable points on the line; do not estimate from points that are not exactly on grid intersections.

The \(y\)-intercept can be read where the line crosses the vertical axis. Then write \(y = mx + b\).

Write the equation in slope-intercept form for the line with slope 3 through \((2,-1)\).

For slope \(3\) through \((2, - 1)\),

\[y - ( - 1) = 3(x - 2).\]

\[y+1=3x-6\]

\[y = 3x - 7.\]

Find the slope through \((1,6)\) and \((5,-2)\).

Use the same point order in both coordinate differences.

\[m=\frac{-2-6}{5-1}=\frac{-8}4=-2\]

Write the line with slope -2 through \((3,4)\) in slope-intercept form.

Substitute into point-slope form, then isolate y.

\[y-4=-2(x-3)\]

\[y=-2x+10\]

Check the point: \(4=-2(3)+10\).

Write the line through \((-4,-1)\) and \((2,8)\) in slope-intercept form.

First find the slope (\(m=\frac{8-(-1)}{2-(-4)}=\frac96=\frac32\)). Use this slope and the point \((-4,-1)\) in point-slope form:

\[y+1=\frac32(x+4)\]

\[y=\frac32x+5\]

Check the other point: \(8=\frac32(2)+5\).

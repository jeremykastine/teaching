Topic 11: The Distributive Property

Assigned to: TSM 098 and TSM 099

Double-click or double-tap the space beneath a problem to show or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

This topic removes parentheses by multiplying an outside factor by every term inside and then combines like terms when possible.

Key definitions

Distributive property: a(b + c) = ab + ac. Outside factor: the factor multiplying a grouped expression. Like terms: terms with matching variable factors and exponents.

Use the distributive property to rewrite the expression.

\(2(c\ + \ 4)\)

The 2 is multiplying the entire quantity in parentheses. Draw one path from the 2 to c and another path from the 2 to 4. The 2 must be used twice: once in each product.

\(2\ \cdot \ c\ + \ 2\ \cdot \ 4\)

\(2c\ + \ 8\)

The first product is 2c, and the second product is 8. A common error is to multiply the first term but leave the second term unchanged. The outside factor must reach every term in the parentheses.

In B4, we multiplied factors. Sometimes one of the factors is an entire group inside parentheses. The distributive property lets the factor outside the parentheses multiply every term inside the group. After the multiplication has been distributed, the parentheses are no longer needed. Every displayed step must remain equivalent to the original expression.

Use the distributive property to rewrite the expression, then simplify the new expression if possible.

\(- 8(m\ + \ 6)\)

Multiply negative 8 by m, and then multiply negative 8 by positive 6.

\(( - 8)\ \cdot \ m\ + \ ( - 8)\ \cdot \ 6\)

\(- 8m\ - \ 48\)

Both terms inside the parentheses are positive. Multiplying either one by a negative factor produces a negative term.

Simplify by using the distributive property.

\(- 3(7m\ - \ 6n\ + \ 9p)\)

There are three terms inside the parentheses, so there must be three products. Treat the middle term as negative 6n when it is multiplied by negative 3.

\(( - 3)(7m)\ + \ ( - 3)( - 6n)\ + \ ( - 3)(9p)\)

\(- 21m\ + \ 18n\ - \ 27p\)

The middle term becomes positive because a negative factor times a negative term is positive. The other two products are negative.

Use the distributive property to rewrite the expression.

\(- 2(p\ - \ 2)\)

\(- 2p\ + \ 4\)

Negative 2 times p is negative 2p. Negative 2 times negative 2 is positive 4.

Use the distributive property to rewrite the expression.

\(7(4p\ + \ 5y\ - \ 3q)\)

\(28p\ + \ 35y\ - \ 21q\)

The 7 is multiplied by all three terms. The sign of the last result is negative because 7 is positive and negative 3q is negative.

Simplify by using the distributive property.

\(- 4(4m\ - \ 2n\ + \ 6p)\)

\(- 16m\ + \ 8n\ - \ 24p\)

The negative outside factor changes the signs of all three results: negative, positive, negative.

Simplify using the distributive property.

\(- ( - 5f\ - \ 3y)\)

When no number is written before a set of parentheses and only a minus sign appears, the implied outside factor is negative 1. Distributing negative 1 changes the sign of every term in the group.

\(- (9h\ + \ 5y)\)

\(- 9h\ - \ 5y\)

Both positive terms become negative.

\(5f\ + \ 3y\)

Negative 1 times a negative term is positive, so both terms become positive.

Practice:

\(- ( - 9m\ + \ 2n\ - \ 3p)\)

\(9m\ - \ 2n\ + \ 3p\)

Every term changes sign: negative 9m becomes positive, positive 2n becomes negative, and negative 3p becomes positive.

Simplify the expression and combine like terms.

\(- 4(t\ - \ 2)\ - \ 4\)

First distribute negative 4 to both terms inside the parentheses.

\(- 4t\ + \ 8\ - \ 4\)

The positive 8 and negative 4 are like terms because both are constants. Combine them after the distribution is complete.

\(- 4t\ + \ 4\)

Simplify the expression and combine like terms.

\(- 3(5y\ - \ 6)\ + \ 2(4y\ + \ 8)\)

Distribute negative 3 through the first group and positive 2 through the second group. Do not begin combining terms until both sets of parentheses have been removed.

\(- 15y\ + \ 18\ + \ 8y\ + \ 16\)

The y-terms combine with one another, and the constants combine with one another.

\(- 7y\ + \ 34\)

Simplify the expression by combining like terms.

\(- 4.7p\ + \ 5.9\ - \ (8p\ + \ 0.3)\ + \ 5.9p\)

A minus sign before parentheses applies to the entire grouped quantity, not only to its first term. A numerical example makes this visible.

\(10\ - \ (2\ + \ 1)\)

\(10\ - \ 3\)

\(7\)

If the parentheses are removed, the 2 and the 1 must both be subtracted. The equivalent ungrouped expression is shown below.

\(10\ - \ 2\ - \ 1\)

\(7\)

Writing 10 − 2 + 1 would give 9, so it would not be equivalent. This is why a minus sign in front of parentheses changes the sign of every term inside.

Distribute the implied negative 1 to the two terms inside the parentheses.

\(- 4.7p\ + \ 5.9\ - \ 8p\ - \ 0.3\ + \ 5.9p\)

Place the three p-terms together and the two constants together.

\(( - 4.7p\ - \ 8p\ + \ 5.9p)\ + \ (5.9\ - \ 0.3)\)

\(- 6.8p\ + \ 5.6\)

Simplify the expression and combine like terms.

\(5t\ + \ 2(1\ - \ 4t)\)

\(5t\ + \ 2\ - \ 8t\)

\(- 3t\ + \ 2\)

The 2 is distributed first. Then the positive 5t and negative 8t combine to give negative 3t.

Simplify the expression by combining like terms.

\(- 3(7y\ + \ 4)\ - \ (2y\ + \ 3)\ - \ 3y\ + \ 7\)

\(- 21y\ - \ 12\ - \ 2y\ - \ 3\ - \ 3y\ + \ 7\)

\(- 26y\ - \ 8\)

The first group has an outside factor of negative 3. The second group has an implied outside factor of negative 1. After both groups are distributed, combine all four y-terms and then combine the constants.

Simplify the expression by combining like terms.

\(- 9(3r\ + \ 7)\ + \ 4(9r\ + \ 2)\)

\(- 27r\ - \ 63\ + \ 36r\ + \ 8\)

\(9r\ - \ 55\)

The r-terms combine to 9r, and the constants negative 63 and positive 8 combine to negative 55.

Expand and simplify.

\(- 5x(x\ - \ 3)\)

The entire factor negative 5x must multiply both terms. In the first product, x times x gives two factors of x. In the second product, negative 5x times negative 3 is positive 15x.

\(( - 5x)(x)\ + \ ( - 5x)( - 3)\)

\(- 5x^{2}\ + \ 15x\)

Expand and simplify.

\(6t^{2}(t\ - \ t^{2}\ + \ 7t^{3})\)

Distribute the full factor 6t squared to all three terms. Then use the product rule from B4 within each product. When powers with the same base are multiplied, the exponents count all of the repeated factors and are added.

\(6t^{2}\ \cdot \ t\ - \ 6t^{2}\ \cdot \ t^{2}\ + \ 42t^{2}\ \cdot \ t^{3}\)

\(6t^{3}\ - \ 6t^{4}\ + \ 42t^{5}\)

The three terms in the result are not like terms because their exponents are different. They cannot be combined by addition.

Practice:

\(- 2x(x\ - \ 2)\)

\(- 2x^{2}\ + \ 4x\)

Practice:

\(2t^{7}(t\ - \ t^{2}\ + \ 4t^{3})\)

\(2t^{8}\ - \ 2t^{9}\ + \ 8t^{10}\)

The distributive property replaces one product containing a grouped sum or difference with a sum of separate products. Multiply the outside factor by every term, keep careful track of the sign attached to each term, and simplify each product. Only after the parentheses are removed should like terms be combined. When the outside factor contains a variable or a power, use the product rule to simplify each distributed product.

Essential facts, definitions, and procedures

  1. What is standard form for a quadratic equation?
  2. When can you use the zero-product property?
  3. What must be included when solving a squared expression equal to a positive number?
  4. State the quadratic formula.
  5. What does the discriminant tell you about real solutions?
Check short-answer key
  1. ax2+bx+c=0, where a ≠ 0.
  2. When a product equals zero.
  3. Both the positive and negative square roots.
  4. x=−b±b2−4ac2a.
  5. Positive: two; zero: one repeated solution; negative: none.

Example problems

Example 1

Solve x2−5x+6=0 by factoring.

Show solution
  1. Factor to (x − 2)(x − 3) = 0.
  2. Set each factor equal to zero: x = 2 or x = 3.

Example 2

Solve (x−4)2=25 by square roots.

Show solution
  1. Take both roots: x − 4 = ±5.
  2. Add 4: x = 9 or x = −1.

Example 3

Solve 2x2+x−3=0 by the quadratic formula.

Show solution
  1. Use a = 2, b = 1, c = −3; the discriminant is 1 + 24 = 25.
  2. x=(−1±5)/4.
  3. The solutions are 1 and −3/2.

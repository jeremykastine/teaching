Essential facts, definitions, and procedures

  1. What is the goal when solving a linear equation?
  2. What should you do with like terms on the same side?
  3. How can you collect variable terms on one side?
  4. What does a false statement such as 0 = 5 mean?
  5. What does a true statement such as 0 = 0 mean after variables cancel?
Check short-answer key
  1. Isolate the variable with coefficient 1.
  2. Combine them.
  3. Add or subtract the same variable term on both sides.
  4. No solution.
  5. Every real number is a solution, if there are no other restrictions.

Example problems

Example 1

Solve 5x − 7 = 2x + 8.

Show solution
  1. Subtract 2x: 3x − 7 = 8.
  2. Add 7: 3x = 15.
  3. Divide by 3: x = 5; both original sides equal 18.

Example 2

Solve 4x + 2 = 4x − 3.

Show solution
  1. Subtract 4x to get 2 = −3.
  2. This is false, so the equation has no solution.

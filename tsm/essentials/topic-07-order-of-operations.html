Topic 7: Order of Operations · Essentials

TSM 098 and TSM 099; selected problems marked for TSM 099 assessment

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is the first priority in order of operations?
  2. Which comes first: multiplication or division?
  3. Which comes first: addition or subtraction?
  4. How should you substitute a negative value into a power?
  5. How does a fraction bar group an expression?
Check short-answer key
  1. Evaluate grouped expressions, working from the inside out.
  2. Neither has priority; work left to right.
  3. Neither has priority; work left to right.
  4. Put the substituted negative value in parentheses.
  5. It groups the entire numerator and the entire denominator.

Example problems

Example 1

Evaluate 18−2(3+1)2.

Show solution
  1. Parentheses give 4; squaring gives 16.
  2. Multiply: 2 × 16 = 32.
  3. Subtract: 18 − 32 = −14.

Example 2

Evaluate 2x2−3x+1 at x = −2. (TSM 099 assessment)

Show solution
  1. Substitute: 2(−2)2−3(−2)+1.
  2. Square first, then multiply: 8 + 6 + 1.
  3. The value is 15.

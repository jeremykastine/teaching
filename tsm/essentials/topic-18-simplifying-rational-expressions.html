Topic 18: Simplifying Rational Expressions · Essentials

TSM 099 only

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What is a rational expression?
  2. When should denominator restrictions be recorded?
  3. What can be canceled?
  4. Why factor before canceling?
  5. How are x − a and a − x related?
Check short-answer key
  1. A quotient of polynomials with a nonzero denominator.
  2. From the original expression, before canceling.
  3. Common nonzero factors of the whole numerator and denominator.
  4. Factoring reveals products rather than separate terms of sums.
  5. They are opposites: a−x=−(x−a).

Example problems

Example 1

Simplify (x2−9)/(x2+3x).

Show solution
  1. The original denominator x(x + 3) excludes x = 0 and −3.
  2. Factor the numerator as (x − 3)(x + 3).
  3. Cancel x + 3 to get (x − 3)/x, retaining both restrictions.

Example 2

Simplify (x−4)/(4−x).

Show solution
  1. Require x ≠ 4.
  2. Since 4 − x = −(x − 4), cancel the common factor.
  3. The value is −1 for x ≠ 4.

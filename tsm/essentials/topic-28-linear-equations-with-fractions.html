Essential facts, definitions, and procedures

  1. How can fractions be cleared from an equation?
  2. Must constant terms also be multiplied by the LCD?
  3. Does multiplying by an LCD change the solution set when denominators are fixed nonzero numbers?
  4. What do you do after clearing denominators?
  5. How should a fractional answer be written?
Check short-answer key
  1. Multiply every term on both sides by an LCD.
  2. Yes; every term must be multiplied.
  3. No.
  4. Solve the resulting linear equation.
  5. In reduced form.

Example problems

Example 1

Solve x/3 + 1/2 = 5/6.

Show solution
  1. Multiply every term by 6: 2x + 3 = 5.
  2. Then 2x = 2, so x = 1.
  3. Check: 1/3 + 1/2 = 5/6.

Example 2

Solve (x − 1)/4 = (x + 2)/6.

Show solution
  1. Multiply by 12: 3(x − 1) = 2(x + 2).
  2. Expand: 3x − 3 = 2x + 4.
  3. Thus x = 7; both original sides equal 3/2.

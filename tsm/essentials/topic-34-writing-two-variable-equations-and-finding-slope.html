Topic 34: Writing Two-Variable Equations and Finding Slope · Essentials

TSM 099 only

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. How do you find slope from two points?
  2. What is point-slope form?
  3. What slope does a horizontal line have?
  4. What slope does a vertical line have?
  5. How can b be found when slope and a point are known?
Check short-answer key
  1. m=(y2−y1)/(x2−x1), when x₂ ≠ x₁.
  2. y−y1=m(x−x1).
  3. Zero.
  4. Undefined.
  5. Substitute the point into y = mx + b and solve for b.

Example problems

Example 1

Write the line through (1, 3) and (3, 7).

Show solution
  1. Slope: (7 − 3)/(3 − 1) = 2.
  2. Use (1, 3): 3 = 2(1) + b, so b = 1.
  3. The equation is y = 2x + 1.

Example 2

A cost is $5 initially plus $3 per item. Write an equation.

Show solution
  1. Let x be the number of items and y the cost in dollars.
  2. The fixed cost is the intercept; the per-item cost is the slope.
  3. Thus y = 3x + 5, for nonnegative whole-number x.

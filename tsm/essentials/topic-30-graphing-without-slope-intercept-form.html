TSM 098 and TSM 099

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does a point on an equation's graph represent?
  2. How do you find an x-intercept?
  3. How do you find a y-intercept?
  4. How many distinct points determine a straight line?
  5. What do x = a and y = b graph as?
Check short-answer key
  1. An ordered pair satisfying the equation.
  2. Set y = 0 and solve for x.
  3. Set x = 0 and solve for y.
  4. Two; a third is useful for checking.
  5. A vertical line and a horizontal line, respectively.

Example problems

Example 1

Graph 2x + y = 4 using intercepts.

Show solution
  1. Set y = 0 to get x = 2, giving (2, 0).
  2. Set x = 0 to get y = 4, giving (0, 4).
  3. Draw the straight line through them; (1, 2) checks the line.

Example 2

Graph x = −3 and y = 2.

Show solution
  1. x = −3 contains all points with x-coordinate −3, so draw a vertical line through −3 on the x-axis.
  2. y = 2 contains all points with y-coordinate 2, so draw a horizontal line through 2 on the y-axis.

Example problems

Example 1

Solve 2x−1=3x+1.

Show solution
  1. Require x ≠ 1, −1.
  2. Multiply by (x − 1)(x + 1): 2(x + 1) = 3(x − 1).
  3. Solve: x = 5; both sides originally equal 1/2.

Example 2

Solve xx−2=2x−2.

Show solution
  1. Require x ≠ 2.
  2. Clearing denominators gives x = 2.
  3. That candidate is excluded, so there is no solution.

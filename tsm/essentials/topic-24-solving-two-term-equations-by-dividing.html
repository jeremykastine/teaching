Topic 24: Solving Two-Term Equations by Dividing · Essentials

TSM 098 and TSM 099

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. What does solving ax = b require when a is nonzero?
  2. Why do the same operation to both sides?
  3. Can a coefficient of zero be divided out?
  4. How do you check a solution?
  5. What is the solution of 0x = 0?
Check short-answer key
  1. Divide both sides by a.
  2. To preserve equality.
  3. No; division by zero is undefined.
  4. Substitute it into the original equation.
  5. Every real number.

Example problems

Example 1

Solve −6x = 42.

Show solution
  1. Divide both sides by −6 to obtain x = −7.
  2. Check: −6(−7) = 42.

Example 2

Solve x/5 = −3.

Show solution
  1. Multiply both sides by 5: x = −15.
  2. Check: −15/5 = −3.

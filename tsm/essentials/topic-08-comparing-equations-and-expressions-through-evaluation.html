Essential facts, definitions, and procedures

  1. What is an expression?
  2. What is an equation?
  3. What is an identity?
  4. What does it mean to solve an equation?
  5. Does matching at one input prove two expressions always equal?
Check short-answer key
  1. A mathematical combination of numbers, variables, and operations without an equality claim.
  2. A statement that two expressions are equal.
  3. An equation true for every allowed value of its variable.
  4. Find all variable values making the equality true.
  5. No; one counterexample disproves an identity, but one match does not prove it.

Example problems

Example 1

Compare 2(x + 3) and 2x + 6 at x = −1, then decide whether they always agree.

Show solution
  1. At −1 both give 4.
  2. Distribution gives 2(x + 3) = 2x + 6 for every x.
  3. The equality is an identity.

Example 2

Classify x + 2 = 5 and x + 2 = x + 5.

Show solution
  1. The first equality holds only at x = 3.
  2. Subtract x from both sides of the second to get 2 = 5.
  3. The second has no solution.

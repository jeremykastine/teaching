Topic 3: Signed Numbers, Including Dividing by Zero · Essentials

TSM 098 and TSM 099

Answer the questions from memory on paper. Then check the answer key. Attempt each example before opening its solution.

Essential facts, definitions, and procedures

  1. How do you add numbers with opposite signs?
  2. How do you subtract a signed number?
  3. What sign results when multiplying two negative numbers?
  4. What sign results when dividing numbers with different signs?
  5. What is the difference between 0 ÷ 5 and 5 ÷ 0?
Check short-answer key
  1. Subtract their absolute values and use the sign of the number with larger absolute value.
  2. Add its opposite.
  3. Positive.
  4. Negative.
  5. 0 ÷ 5 = 0; division by zero is undefined.

Example problems

Example 1

Evaluate −8 − (−3) + 2.

Show solution
  1. Subtracting −3 means adding 3.
  2. −8 + 3 + 2 = −5 + 2 = −3.

Example 2

Evaluate (−24) ÷ (−6), and explain why 7 ÷ 0 is undefined.

Show solution
  1. Equal signs give a positive quotient: (−24) ÷ (−6) = 4.
  2. A quotient 7 ÷ 0 would require a number q with 0 × q = 7.
  3. No such number exists.

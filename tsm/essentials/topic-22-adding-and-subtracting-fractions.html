Check short-answer key
  1. A common denominator.
  2. The numerators; keep the common denominator.
  3. Multiply numerator and denominator by the same missing factor.
  4. It gives the smallest convenient common denominator.
  5. Simplify the result.

Example problems

Example 1

Compute 5/6 − 1/4.

Show solution
  1. The LCD is 12.
  2. Rewrite as 10/12 − 3/12 = 7/12.

Example 2

Compute 2/9 + 5/6.

Show solution
  1. The LCD is 18.
  2. Rewrite as 4/18 + 15/18 = 19/18.
  3. This is already reduced; it also equals 1 and 1/18.

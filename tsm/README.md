# TSM

Lecture notes and planning documents for the co-listed TSM 098–099 course.

- `../index.html` is the single Teaching page with direct links to lecture notes, homework, and practice tests under TSM 098 / 099. `tsm/index.html` redirects there.
- `lecture-notes.html` is the table of contents for the browser edition.
- `lessons/` contains one HTML file for each of the 37 topics.
- `planning/` contains the co-listed course schedule.
- `specifications/` contains the lecture-note and test specifications.

The HTML notes are the maintained lecture-note source and include 376 worked solutions revealed or hidden by double-clicking or double-tapping the solution area (or focusing it and pressing Enter/Space). Each concealed solution uses white text on a white background and preserves its natural height, providing a work area sized to the amount of solution content. The complete solution text stays in the HTML and rendered document for text extraction and assistive reading; revealing it changes only its formatting. Mathematical notation is rendered with MathJax 4, with inline and display formulas wrapping to the available width and no formula scrollbars or vertical clipping. Topic 5, Evaluating Powers and Square Roots, contains 21 separately revealed worked examples: 16 on powers followed by the five square-root examples. Topic 7 contains eight shared examples followed by eight TSM 099-only examples, with a visible course boundary. The shared portion covers numerical precedence, linear expressions, constant denominators, linear combinations, and factored polynomials; the extension covers expanded polynomials, variable denominators, and the quadratic formula. All divisions in Topic 7 produce integers. Topic 2 introduces exponent notation briefly for prime factorization; full power instruction follows signed numbers and fractions in Topic 5. Established topic numbers and lesson URLs are retained.

Edit lecture notes directly in `lessons/`. All lecture-note content is maintained in HTML; no parallel Word documents are kept.

## Homework

Compact PDF homework assignments are linked from `homework.html`. See [the homework design and coverage map](homework/README.md) for priorities, topic groupings, editable sources, and rebuild instructions. Students work on separate paper and upload one best representative page in Blackboard.

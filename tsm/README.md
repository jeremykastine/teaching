# TSM

Lecture notes and planning documents for the co-listed TSM 098–099 course.

- `index.html` is the table of contents for the browser edition.
- `lessons/` contains one HTML file for each of the 37 topics.
- `planning/` contains the co-listed course schedule.
- `specifications/` contains the lecture-note and test specifications.

The HTML notes are the maintained lecture-note source and include 211 worked solutions revealed or hidden by double-clicking or double-tapping the solution area (or focusing it and pressing Enter/Space). Each concealed solution uses white text on a white background and preserves its natural height, providing a work area sized to the amount of solution content. The complete solution text stays in the HTML and rendered document for text extraction and assistive reading; revealing it changes only its formatting. Mathematical notation is rendered with MathJax 4, with inline and display formulas wrapping to the available width and no formula scrollbars or vertical clipping. Topic 5 contains five separately revealed worked problems.

Edit lecture notes directly in `lessons/`. All lecture-note content is maintained in HTML; no parallel Word documents are kept.

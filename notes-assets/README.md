# OpenStax textbook figures

These 531 figures support the Statistics and College Algebra lecture notes. `manifest.json` maps each original OpenStax resource URL to its local SVG file. Most SVG containers embed a losslessly encoded WebP rendition of the original raster figure; source SVGs remain vector graphics. No external image requests are needed to display the lecture notes.

Sources: OpenStax *Introductory Statistics 2e* (Barbara Illowsky and Susan Dean) and *College Algebra 2e* (Jay Abramson), Rice University. Retrieved October 27, 2026.

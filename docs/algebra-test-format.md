# Algebra test format

## Minimal answer-area labels (October 26, 2026)

- Keep each student answer area as clean as possible: include only the question number, necessary part labels such as (a) and (b), and the applicable points. For a single-part question, use just its number and points; do not invent a part label.
- Do not print redundant answer-type words or descriptors such as “Polynomial,” “Value,” “Result,” “Solution,” “Equation,” or “Factored form” in the answer area. Put the task and required answer form in the question prompt.
- When several answers must be distinguished, label the requested outputs as parts in the prompt and use only those matching part labels in the response areas. Add no explanatory wording merely to fill a response area.
- Retain only structures essential to answering the question, such as a required blank graph grid with its axis labels or a table students must complete. These do not justify extra answer-type captions.
- Use the same minimal question/part labels in the matched instructor key, alongside the actual answers and points. This is a standing rule for future generation; do not regenerate existing tests solely to apply it.

## Final-answer directions and grading (October 26, 2026)

This policy applies to every test, exam, retake, diagnostic, final, and practice version and overrides any conflicting method or presentation language elsewhere in these specifications.

- Student-facing directions and individual prompts must never ask students to show work, show substitution, show checks, show partial products, explain a calculation method, or display particular intermediate steps. Do not prescribe a solution method or require separate-paper work.
- Ask only for the requested final result, such as an exact value, simplified expression, factorization, solution set, graph, or requested function feature. Use concise directions such as “Write exact final answers in the right column.” Retain the calculator policy.
- Grade the requested answer in the right-hand response area. Do not imply that shown work earns partial credit or that missing work loses credit. Assign points to final-answer outputs, never to intermediate work, checks, or use of a particular method.
- References to methods or checks describe authoring, expected difficulty, internal verification, or instructor-key content only. They must not become student directions, intermediate response rows, or method-based grading criteria. Independently solve and verify every item before delivery.

## Calculator directions

Include this instruction in the student directions of every future test/exam and practice test/exam, including unit tests, retakes, diagnostics, and finals: **"Students may use a basic, non-scientific calculator only."** A basic four-function calculator is permitted; scientific, graphing, and CAS calculators are not permitted.

## Version identifiers

For every newly generated test/exam or practice test/exam version, independently choose a random five-digit integer from 10000 through 99999 as its version identifier. Apply this to single versions and every version in a requested batch, including unit tests, retakes, diagnostics, and finals. Do not use timestamps, sequential numbering, lettered labels, or batch suffixes; no numerical ordering is required. Duplicate identifiers are acceptable; no uniqueness check or registry is required. Use the same identifier on the student test, corresponding answer key, and filename when practical. Preserve existing identifiers when only reformatting existing versions.

## Student test

- Combine problem statements and final-answer spaces on the same pages. Use US Letter portrait pages with print-safe margins. Within the usable width, the questions occupy the left two-thirds and answers occupy the right one-third.
- Align every answer area vertically with its question. Keep each main question and its response rows together on one page. Use natural content flow; do not add working space to fill a page.
- Aim for one or two student pages (at most one physical sheet front/back). Longer finals may use three or more pages when needed for legibility and adequate answer space.
- Include title, version identifier, name, and concise directions to write exact final answers in the right column. Do not include a course-section field.
- Put blank grids or other structures students complete in the answer column. Put supplied graphs students interpret with the problem statement. Keep graph labels and scales legible at printed size.
- Keep response areas open, without internal answer baselines. Use solid rules between main questions, a vertical question/answer divider, and light dotted or dashed rules only between subparts. Put each part's points at the bottom of its answer area; do not repeat the main question's point total in its heading.
- Never embed hidden, white, or transparent key answers on student pages.

## Instructor answer key

- Aim for one page, front only. For one, two, or three student pages, use exactly one, two, or three columns respectively.
- Label each key column with its corresponding student test page. Preserve the exact vertical row heights, question boundaries, subpart boundaries, labels, and point positions for that page's answer column. Column width may differ; vertical positions must match without scaling the page.
- Build a shared layout from the key's content, then generate the student pages by omitting answers from the same fixed geometry. The key contains concise answers and necessary grading information, including completed graphs when appropriate.
- Wrap long answers into readable lines and increase matched row heights when needed. Do not shrink notation or graphs to force a page-count target.
- If a longer test needs more than three pages, use additional key pages with up to three page-matching columns per page. Keep all answers vertically matched and retain concise, readable type. This is the fallback when a one-page key is impractical.

## Combined PDF and duplex printing

- Default order: combined student test, any necessary completely blank page, then instructor key. There is no separate student answer sheet.
- The test and key each begin on an odd-numbered PDF page. An odd-length test receives a blank page before its key; an even-length test does not.
- If multiple complete test/key packets are merged, pad after a packet as needed so the next test starts on a fresh front side.
- Optional instructor-only compliance material is included only when requested and starts on a fresh front side after the key.
- Use duplex printing with long-edge flipping. Retain the existing filename and identifier when only reformatting an existing version.

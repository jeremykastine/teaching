# Shared test presentation - October 30, 2026

These requirements control all TSM 098, TSM 099, MATH 101, and MSC 201 unit tests, retakes, diagnostics, finals, and practice versions. They supersede older presentation, header, footer, key-width, page-count, and Statistics response instructions. Course specifications still control mathematical content, coverage, scoring, and difficulty.

## Student header and directions

- US Letter portrait, at least 0.5-inch print-safe side margins; print at actual size.
- Upper left: course name and test name. Upper right: an independently random five-digit version integer, 10000 through 99999. Match that number on the key. No timestamps, sequential identifiers, or batch suffixes. Repeated random identifiers are acceptable.
- Beneath the title/version header, provide both Name and Date lines. No section field.
- Print: **Students may use a basic, non-scientific calculator only. No notes or other technology.**
- For written-response tests print: **Write final answers in the space provided in the right column.** Grade those final answers only. Do not request work, checks, prescribed methods, or intermediate steps.
- For Statistics print: **Circle one response per question in the right column.** This replaces written-response directions for multiple-choice tests.

## Student questions and responses

- Prefer the entire student test on the front of one sheet. Additional pages are permitted when necessary for legible questions, graphs, and response spaces. Use natural content heights; do not stretch rows to fill a sheet or shrink type to force the target.
- TSM and College Algebra: questions in the left two-thirds, vertically matched final-answer areas in the right third. Put supplied interpretation graphs with the questions and blank grids students complete in the response areas.
- Statistics: approximately equal left and right columns. Put the question and any supplied figure on the left; all four choices A-D on the right, where students circle their selection. Keep a whole question and its choices together.
- Use solid rules between main questions and a vertical question/response divider. Light dashed rules may separate internal parts. No internal writing baselines.
- Keep response labels minimal: question number, necessary part labels, and points. When different outputs require labels, match those labels explicitly in the prompt. Retain only essential tables or graph structures. No redundant answer-type captions.
- Points belong at the bottom of response areas, not in question headings. Do not embed hidden or recolored key content on student pages.

## Footers

- No routine footer, page number, course name, version, key label, or other metadata at the bottom.
- Only a student page followed by another student page has a continuation prompt. On an odd student page use **Test continues on the other side of the sheet.** On an even student page use **Test continues on the next sheet.**
- The last student page, key pages, and blank padding pages have no footer. A key is not a continuation of the student test.

## Instructor keys

- At the top print only the matching five-digit version number, large, bold, and horizontally centered. Do not print course/test names, "Instructor key," "Answer key," explanations about matching positions, total points, or student fields.
- Use one compact column per student page, labeled **TEST PAGE 1**, **TEST PAGE 2**, etc. Start at the left margin, keep each column only as wide as its content needs, and leave unused page width blank. Do not expand a single column across the page.
- Share the exact vertical geometry with the student response areas: same question and subpart boundaries, row heights, labels, and point baselines. Wrap long answers into readable lines and increase shared row heights as needed.
- For Statistics, print the correct choice letter at the exact vertical text position occupied by that choice on the student page, including when choices wrap. Merely centering a letter in its question's row is insufficient. Omit incorrect choices, question text, and explanations from the key.
- Aim for one key page with up to three page-matching columns. Longer tests may have additional key pages; keep positions fixed without scaling. Include completed graphs when they are the requested answers.

## Batches and duplex printing

- Generate 20 fresh versions per requested assessment in one combined PDF. Diagnostics and finals are separate assessment sets unless explicitly requested as one interchangeable set.
- Each packet is student page(s), a completely blank padding page if needed, then the instructor key page(s). Both the student test and key start on odd-numbered PDF pages.
- Pad the end of each packet, including the last, so the next packet starts on a fresh front. Padding has no marks or text. Print duplex, long-edge flip, actual size.
- Do not add covers, audit pages, or worked solutions unless requested. Keep seeds, selected question IDs, shuffled choices, mathematical checks, and geometry in a separate reproduction record.
- Store instructor batches under `_instructor/assessments/` without adding links to course pages, navigation, or student indexes. The teaching repository is public: unlinked files remain publicly accessible to repository visitors. This is discoverability management, not access control.

## Verification

Check the batch count and identifiers, actual content variation, course blueprints and point totals, answer correctness, shuffled choice mapping, all student/key row coordinates, Statistics choice-letter baselines, no hidden student answers, readable rendering and graphs, page margins, continuation text, blank pages, and odd-page test/key starts. Render every nonblank page for inspection; keep image artifacts outside committed course content.

Lecture 17: Function Notation, Inputs, and Outputs

Assessment coverage Test 4

Double-click or double-tap the space beneath a problem to reveal or hide its solution. With a keyboard, focus that space and press Enter or Space.

Overview

When \(y\) is a function of \(x\), writing \(y(x)\) emphasizes the input. Naming the rule \(f\) or \(g\) makes it easier to refer to the same calculation at different inputs.

Key definitions

A function assigns exactly one output to every input in its domain. The notation \(f(3)\) names the output at input \(3\). In \(f(x)=3\), the output is given and the input is the unknown.

For \(y=2x-5\), write \(y(x)\) and evaluate \(y(-2)\). Then name the same rule \(f\) and find \(f(4)\).

Write \(y(x)=2x-5\). Substituting gives \(y(-2)=2(-2)-5=-9\). With \(f(x)=2x-5\), the same calculation gives \(f(4)=8-5=3\).

Rewrite the entire expression using one named function. Leave the unrelated \(7\) outside and keep the inputs unevaluated.

\(2(3)^2-3(3)+1+7+2(5)^2-3(5)+1-\bigl(2(x+1)^2-3(x+1)+1\bigr)\)

The repeated calculation squares the input, doubles the square, subtracts three times the input, and adds one. Let \(f(t)=2t^2-3t+1\). The original expression is \(f(3)+7+f(5)-f(x+1)\).

Use this table to find \(g(-2)\) and all tabulated inputs for which \(g(x)=3\).

\[\begin{array}{c|rrrr}x&-2&0&2&4\\\hline g(x)&3&1&3&-1\end{array}\]

The column at input \(-2\) has output \(3\), so \(g(-2)=3\). Scan the output row for \(3\). The corresponding inputs are \(-2\) and \(2\).

Use the displayed graph of \(y=f(x)\) to read \(f(3)\) and solve \(f(x)=3\).

The height over \(x=3\) is \(3\), so \(f(3)=3\). The horizontal line at height \(3\) meets the graph at \(x=-1\) and \(x=3\), so there are two solutions.

For \(f(x)=x^2-4\), find \(f(-3)\), then solve \(f(x)=-3\).

Evaluation gives \(f(-3)=(-3)^2-4=5\). The equation for the unknown input is \(x^2-4=-3\), so \(x^2=1\) and \(x=\pm1\).

Which relation gives \(y\) as a function of \(x\): the pairs \((0,2),(1,2),(2,5)\), or the pairs \((0,2),(0,3),(2,5)\)?

The first gives one output for each listed input. Repeated outputs are allowed. The second gives two outputs at \(x=0\), so it is not a function of \(x\).

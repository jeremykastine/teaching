Lecture 12: Absolute value equations

Assessment coverage TSM 098 test 3 · TSM 099 test 3

Overview

Absolute value gives a distance. Once the absolute value is isolated, use that distance to decide how many cases to solve.

Key definitions

The absolute value \(|u|\) is the distance from \(u\) to \(0\). For real \(u\), the principal square root \(\sqrt{u^2}=|u|\). A distance cannot be negative.

Solve \(|2x-3|=5\).

The inside can be \(5\) or \(-5\). The equations \(2x-3=5\) and \(2x-3=-5\) give \(x=4\) and \(x=-1\).

Solve \(3|x+2|-4=11\).

Add \(4\), then divide by \(3\) to get \(|x+2|=5\). Solve \(x+2=5\) or \(x+2=-5\). The solutions are \(3\) and \(-7\).

Solve \(|4x+6|=0\).

Only zero has distance zero. Solve \(4x+6=0\) to get \(x=-3/2\).

Solve \(2|x-4|+3=1\).

Isolation gives \(|x-4|=-1\). The equation has no real solution.

Compare \(\sqrt{(-7)^2}\) and \(\sqrt{7^2}\), then simplify \(\sqrt{(x-3)^2}\) for arbitrary real \(x\).

Both numerical square roots are \(7\). In the last expression, \(x-3\) could be negative, so the general answer is \(|x-3|\).

Solve \(12-2|3x-1|=4\) and check both solutions.

Subtract \(12\) and divide by \(-2\) to get \(|3x-1|=4\). The two inside values give \(x=5/3\) or \(x=-1\). Each makes the absolute value \(4\) and the original left side \(12-8=4\).
